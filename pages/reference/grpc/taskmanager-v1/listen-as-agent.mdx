建立服务器流式连接，把任务交付给可执行任务的 agent 执行。此方法会从 Task Manager 到 agent 创建持久连接，使服务器可以在任务可用时将其推送给 agent。agent 会收到与其 selector 条件（例如实体 ID）匹配的任务流。该流交付三类请求：- ExecuteRequest：包含要由 agent 执行的新任务 - CancelRequest：表示应取消某个任务 - CompleteRequest：表示应完成某个任务。这是可执行任务的 agent 实时接收和处理任务的主要方法。agent 应保持此连接，并根据自身能力处理传入任务。当 agent 收到任务时，应使用 `UpdateStatus` RPC 更新任务状态，将进度信息回传给 Task Manager。当请求设置了 `heartbeat_interval_ms` 时，会在没有任务交付的空闲期间定期发送 heartbeat 消息来维持连接。

### 请求

**ListenAsAgentRequest**

此端点需要一个对象。

- `agent_selector` — _object_

- `heartbeat_interval_ms` — _uint_ — 发送 heartbeat 事件的时间间隔，单位为毫秒。如果未设置或设为 0，则不发送 heartbeat 消息。

### 响应

**ListenAsAgentResponse**

此端点返回一个对象。

- `request` — _object_

- `heartbeat` — _object_ — 表示流仍然存活的 heartbeat 消息。
