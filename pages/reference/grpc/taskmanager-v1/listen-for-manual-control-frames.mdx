# ListenForManualControlFrames

```json
{
  "task_id": "example"
}
```

```json
{
  "frame": {
    "task_id": "example",
    "epoch_micros": 42,
    "sequence": 42,
    "creation_time": {
      "seconds": 42,
      "nanos": 42
    },
    "specification": {
      "type_url": "example",
      "value": "bytes"
    }
  }
}
```

建立服务器流式连接，用于接收特定任务的手动控制帧。agent 调用此 RPC，订阅其正在执行任务的手动控制帧。Task Manager 会转发来自操作员 `SendManualControlFrames` 流的帧，其中包含 epoch 和 sequence 元数据，用于处理并发控制会话并检测过期帧。agent 应在将任务状态设为 `STATUS_EXECUTING` 前打开此流，以确保操作员开始发送帧后能立即接收控制输入。当任务达到 `STATUS_DONE_OK` 或 `STATUS_DONE_NOT_OK` 终止状态时，该流结束。

### 请求

**ListenForManualControlFramesRequest**

此端点需要一个对象。

- `task_id` — _string_ — agent 监听的手动控制任务 ID。

### 响应

**ListenForManualControlFramesResponse**

此端点返回一个对象。

- `frame` — _object_ — 手动控制帧。包含控制指令和排序元数据。
