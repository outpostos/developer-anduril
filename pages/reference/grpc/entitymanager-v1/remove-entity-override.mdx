# RemoveEntityOverride

```json
{
  "entity_id": "example",
  "field_path": [
    "example"
  ]
}
```

```json
{}
```

移除实体组件的覆盖。

### 请求

**RemoveEntityOverrideRequest**

此端点需要一个对象。

- `entity_id` — _string_ — 要移除覆盖的实体 ID。

- `field_path` — _list of strings_ — 要从给定 entityId 的覆盖存储中移除的字段路径。
