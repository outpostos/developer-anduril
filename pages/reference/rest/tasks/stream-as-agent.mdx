# 作为 agent 流式传输

**端点**: `POST /api/v1/agent/stream`

**cURL**

```bash
curl -X POST https://example.developer.anduril.com/api/v1/agent/stream \
     -H "Authorization: Bearer <token>" \
     -H "Content-Type: application/json" \
     -d '{}'
```

使用 Server-Sent Events (SSE) 建立服务器流式连接，把任务交付给可任务化 agent 执行。此方法会从 Tasks API 到 agent 创建连接，将相关任务流式传输给监听 agent。agent 会收到与任务 selector 条件所指定实体匹配的任务流。该流交付三类请求：- `ExecuteRequest`：包含要由 agent 执行的新任务 - `CancelRequest`：表示应取消某个任务 - `CompleteRequest`：表示应完成某个任务。此外，会定期发送 heartbeat 消息以维持连接。这是推荐的可任务化 agent 实时接收和处理任务的方法。agent 应保持与此流的连接，并根据自身能力处理传入任务。当 agent 收到任务时，应使用 `UpdateStatus` 端点更新任务状态，将进度信息回传给 Tasks API。

### 认证

- `Authorization` — _Bearer_ — Bearer 认证，格式为 `Bearer <token>`，其中 token 是你的认证令牌。

### 请求

此端点需要一个对象。

- `agentSelector` — _object · optional_ — 用于确定 agent 接收哪些任务的 selector 条件。

- `heartbeatIntervalMs` — _integer · optional_ — 发送 heartbeat 事件的时间间隔，单位为毫秒。默认值为 30000（30 秒）。

### 响应

在任务可用时向 agent 返回任务流。

- `heartbeat` — _object_

或

- `agent_request` — _object_ — 任务动作请求的包装器：执行、取消或完成。

### 错误

400

Bad Request 错误

401

Unauthorized 错误
