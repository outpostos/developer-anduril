# 流式传输任务

**端点**: `POST /api/v1/tasks/stream`

**cURL**

```bash
curl -X POST https://example.developer.anduril.com/api/v1/tasks/stream \
     -H "Authorization: Bearer <token>" \
     -H "Content-Type: application/json" \
     -d '{}'
```

使用 Server-Sent Events (SSE) 建立服务器流式连接，实时交付任务更新。

首次连接时，该流会交付所有现有的非终止任务，随后实时交付任务创建和状态变更更新。此外，会定期发送 heartbeat 消息以维持连接。

### 认证

- `Authorization` — _Bearer_ — Bearer 认证，格式为 `Bearer <token>`，其中 token 是你的认证令牌。

### 请求

此端点需要一个对象。

- `heartbeatIntervalMs` — _integer · optional_ — 发送 heartbeat 事件的时间间隔，单位为毫秒。默认值为 30000（30 秒）。

- `rateLimit` — _integer · optional_ — 给定任务发生一次更新后，同一任务下一次更新发送前的时间间隔，单位为毫秒。如果设置，值必须 &gt;= 250。

- `excludePreexistingTasks` — _boolean · optional_ — 可选标志，仅包含流启动后创建或更新的任务，不包含此前既有任务。如果未设置或为 false，该流会包含任何新任务和任务更新，以及所有既有任务。

- `taskType` — _object · optional_ — 可选过滤器，仅返回特定类型的任务。如果未提供，则流式传输所有任务类型。

- `updateStartTime` — _string · optional_ — 如果提供，则返回自给定时间以来更新过的任务。

- `parentTaskId` — _string · optional_ — 用于筛选具有特定父任务 ID 的任务。注意：此过滤器与所有其他过滤字段（`updateStartTime`、`assignee`、`statusFilter`、`taskType`）互斥。请提供 `parentTaskId`，或提供其他过滤器的任意组合，但不能同时提供。

- `assignee` — _object · optional_ — 用于筛选分配给特定 principal 的任务。

- `statusFilter` — _object · optional_ — 任务状态过滤器（包含或排除）。

### 响应

在任务更新发生时返回任务更新流。

- `heartbeat` — _object_

或

- `task_event` — _object_ — 包含任务事件相关信息。

### 错误

400

Bad Request 错误

401

Unauthorized 错误
