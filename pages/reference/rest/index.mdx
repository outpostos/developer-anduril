### 认证

- `Authorization` — _Bearer_ — Bearer 认证，格式为 `Bearer <token>`，其中 token 是你的认证令牌。

### 路径参数

- `entityId` — _string · required_ — 要返回的实体 ID

### 响应

实体获取成功

- `entityId` — _string · optional_ — 实体的全局唯一标识符 (GUID)。这是必填字段。

- `description` — _string · optional_ — 人类可读的实体描述，有助于调试和人工追踪。如果此字段为空，Entity Manager API 会自动生成。

- `isLive` — _boolean · optional_ — 表示实体处于活动状态，生命周期状态应为 CREATE 或 UPDATE。发布实体时将此字段设为 true。

- `createdTime` — _datetime · optional_ — 实体生产者首次知晓该实体的时间。如果此字段为空，Entity Manager API 会使用首次收到实体时的当前时间戳。例如，无人机首次上电时，可能会把启动时间报告为创建时间。该时间戳在实体生命周期内不会改变。

- `expiryTime` — _datetime · optional_ — 使实体过期并更新 is_live 标志的未来时间。对于持续更新的实体，过期时间也会更新。在某些情况下，这可能与 is_live 不同。例如，带有导出到外部系统任务的实体，即使过期后也必须保持活动。发布预填充实体时，此字段必填。过期时间必须在未来，但距离当前时间小于 30 天。

- `noExpiry` — _boolean · optional_ — 仅当实体包含应在其直接操作上下文之外供其他任务或集成使用的信息时，才使用 noExpiry。例如，对于在多个行动或任务中持续相关的长期地理实体，可使用 noExpiry。

- `status` — _object · optional_ — 关于实体当前正在执行事项的人类可读描述。

- `location` — _object · optional_ — 与实体相关的地理空间数据，包括其位置、运动学和姿态。填充此字段（以及 `location_uncertainty`）或 `kinematics` 二者之一，不要同时填充。同时填充可能导致实体运动学数据冲突或不一致。

- `locationUncertainty` — _object · optional_ — 表示实体位置和运动学的不确定性。

- `kinematics` — _object · optional_ — 与实体相关、粒度高于 Location 的运动学数据。对于航迹实体优先使用此字段。填充 `location`/`location_uncertainty` 或此字段二者之一，不要同时填充。同时填充可能导致实体运动学数据冲突或不一致。

- `geoShape` — _object · optional_ — 实体的地理空间表示，包括覆盖区域而非固定点的实体。

- `geoDetails` — _object · optional_ — 关于地理空间区域或点表示内容的附加详细信息，以及视觉显示详情。

- `aliases` — _object · optional_ — 显示在 Lattice UI 侧边栏中的实体名称。还包含其他系统可用于引用同一实体的标识符。

- `tracked` — _object · optional_ — 如果此实体由另一个实体跟踪，该组件包含其跟踪方式相关数据。

- `correlation` — _object · optional_ — 如果此实体已与另一个实体关联或解除关联，该组件包含相关关联或解除关联信息。

- `milView` — _object · optional_ — 实体视图。

- `ontology` — _object · optional_ — 本体定义实体在 Lattice 中的分类，并改进数据检索和集成。它构建实体的标准化表示。

- `sensors` — _object · optional_ — 详述实体可用的传感器。

- `payloads` — _object · optional_ — 详述实体可用的 payload。

- `powerState` — _object · optional_ — 详述实体的电源。

- `provenance` — _object · optional_ — 此实体的主要数据来源。

- `overrides` — _object · optional_ — 覆盖数据的来源。

- `indicators` — _object · optional_ — 描述实体的特定特征以及可对实体执行的操作。例如，“simulated” 告知操作员该实体来自仿真，“deletable” 告知操作员（以及系统）可对该实体执行删除操作。

- `targetPriority` — _object · optional_ — 与实体关联的优先级，例如它是否为威胁或高价值目标。

- `signal` — _object · optional_ — 描述实体的信号特征，主要在实体为感兴趣信号时使用。

- `transponderCodes` — _object · optional_ — 描述与 Mode 1、2、3、4、5、S、C 询问相关的任何应答机代码的消息。这些代码与 ADS-B 模式相关。

- `dataClassification` — _object · optional_ — 描述实体整体级别和逐字段级别的安全密级。

- `taskCatalog` — _object · optional_ — 实体可执行任务的目录。

- `media` — _object · optional_ — 与实体关联的媒体，例如视频、图片或缩略图。

- `relationships` — _object · optional_ — 此实体与通用作战图 (COP) 中其他实体之间的关系。

- `visualDetails` — _object · optional_ — 与客户端中实体显示相关的视觉详情。

- `dimensions` — _object · optional_ — 实体的物理尺寸。

- `routeDetails` — _object · optional_ — 关于实体路线的附加信息。

- `schedules` — _object · optional_ — 与此实体关联的日程。

- `health` — _object · optional_ — 实体报告的健康指标或连接状态。

- `groupDetails` — _object · optional_ — 与此实体关联的组详情。

- `supplies` — _object · optional_ — 包含实体的相关补给信息，例如燃料。

- `orbit` — _object · optional_ — 空间对象的轨道信息。

- `symbology` — _object · optional_ — 遵循现有标准的实体符号/图标体系。
