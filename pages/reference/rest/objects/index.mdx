# 上传对象

**端点**: `POST /api/v1/objects/:objectPath`

**cURL**

```bash
curl --data-binary "path/to/file" -X POST https://example.developer.anduril.com/api/v1/objects/objectPath \
  -H "Time-To-Live: 123" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/octet-stream"
```

**200 成功**

```json
{
  "content_identifier": {
    "path": "string",
    "checksum": "string"
  },
  "size_bytes": 1,
  "last_updated_at": "2024-01-15T09:30:00Z",
  "expiry_time": "2024-01-15T09:30:00Z"
}
```

上传对象。对象大小必须不超过 1 GiB。

### 认证

- `Authorization` — _Bearer_ — Bearer 认证，格式为 `Bearer <token>`，其中 token 是你的认证令牌。

### 路径参数

- `objectPath` — _string · required_ — 要上传的对象路径。

### 标头

与对象关联的可选过期 TTL。该值表示对象在本地存储中存在的纳秒数。如果未提供 TTL，服务器会应用默认 TTL。多数情况下默认 TTL 为 90 天，但也可能更高或更低，取决于你的环境保留要求。

控制对象如何在 mesh 中分发。如果设为 `force`，对象会强制分发到所有节点。强制分发的对象受大小限制约束。
