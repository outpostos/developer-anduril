# 列出对象

**端点**: `GET /api/v1/objects`

**cURL**

```bash
curl https://example.developer.anduril.com/api/v1/objects \
     -H "Authorization: Bearer <token>"
```

**200 已获取**

```json
{
  "path_metadatas": [
    {
      "content_identifier": {
        "path": "string",
        "checksum": "string"
      },
      "size_bytes": 1,
      "last_updated_at": "2024-01-15T09:30:00Z",
      "expiry_time": "2024-01-15T09:30:00Z"
    }
  ],
  "next_page_token": "string"
}
```

列出你的环境中的对象。你可以定义前缀来列出对象子集。如果未设置前缀，Lattice 会返回所有可用对象。默认情况下，此端点只列出本地对象。

### 认证

- `Authorization` — _Bearer_ — Bearer 认证，格式为 `Bearer <token>`，其中 token 是你的认证令牌。

### 查询参数

- `prefix` — _string · optional_ — 根据指定前缀路径筛选对象。如果未指定路径，则返回所有对象。

- `sinceTimestamp` — _datetime · optional_ — 设置在整个环境中查询对象时最旧对象的时间范围。

- `pageToken` — _string · optional_ — 服务返回的 Base64 和 URL 编码游标，用于继续分页。

- `allObjectsInMesh` — _boolean · optional_ — 列出 Lattice Mesh 中所有环境节点上的对象。

- `maxPageSize` — _integer · optional_ — 设置单页应返回的最大条目数。

### 响应

操作成功

- `path_metadatas` — _list of objects_

- `next_page_token` — _string · optional_

### 错误

400

Bad Request 错误

401

Unauthorized 错误

500

Internal Server 错误
