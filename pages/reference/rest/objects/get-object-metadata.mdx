# 获取对象 metadata

**端点**: `HEAD /api/v1/objects/:objectPath`

```bash
curl -X HEAD https://example.developer.anduril.com/api/v1/objects/objectPath \
     -H "Authorization: Bearer <token>"
```

**200 OK**

```json
{}
```

返回指定对象路径的元数据。可用它获取对象大小 (size_bytes)、过期时间 (expiry_time) 或最新更新时间戳 (last_updated_at) 等元数据。

### 认证

- `Authorization` — _Bearer_ — Bearer 认证，格式为 `Bearer <token>`，其中 token 是你的认证令牌。

### 路径参数

- `objectPath` — _string · required_ — 要查询的对象路径。

### 响应标头

### 响应

操作成功

### 错误

400

Bad Request 错误

401

Unauthorized 错误

500

Internal Server 错误
