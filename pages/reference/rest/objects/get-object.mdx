# 获取对象

**端点**: `GET /api/v1/objects/:objectPath`

**cURL**

```bash
curl https://example.developer.anduril.com/api/v1/objects/objectPath \
     -H "Authorization: Bearer <token>"
```

使用 objectPath 路径参数从你的环境中获取对象。

### 认证

- `Authorization` — _Bearer_ — Bearer 认证，格式为 `Bearer <token>`，其中 token 是你的认证令牌。

### 路径参数

- `objectPath` — _string · required_ — 要获取的对象路径。

### 标头

如果设置该标头，Lattice 会使用指定压缩方法压缩响应。如果未定义该标头，或压缩方法设为 `identity`，则不会对响应应用压缩。

允许值

:

表示客户端对响应优先级的偏好。该值是 RFC 9218 定义的结构化标头。如果未设置该标头，Lattice 会使用环境中设置的默认优先级。不支持增量交付指令，相关指令会被忽略。

### 响应标头

响应正文使用的压缩方式。

### 响应

操作成功

### 错误

400

Bad Request 错误

401

Unauthorized 错误

404

Not Found 错误

500

Internal Server 错误
