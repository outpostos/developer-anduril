# 删除对象

**端点**: `DELETE /api/v1/objects/:objectPath`

**cURL**

```bash
curl -X DELETE https://example.developer.anduril.com/api/v1/objects/objectPath \
     -H "Authorization: Bearer <token>"
```

根据 objectPath 路径参数从你的环境中删除对象。

### 认证

- `Authorization` — _Bearer_ — Bearer 认证，格式为 `Bearer <token>`，其中 token 是你的认证令牌。

### 路径参数

- `objectPath` — _string · required_ — 要删除的对象路径。

### 响应

操作成功

### 错误

400

Bad Request 错误

401

Unauthorized 错误

500

Internal Server 错误
