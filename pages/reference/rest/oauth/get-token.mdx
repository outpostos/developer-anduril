# 获取 OAuth2 令牌

**端点**: `POST /api/v1/oauth/token`

**cURL**

```bash
curl -X POST https://example.developer.anduril.com/api/v1/oauth/token \
     -H "Authorization: Bearer <token>" \
     -H "Content-Type: application/x-www-form-urlencoded" \
     -d "grant_type=client_credentials"
```

**200 成功**

```json
{
  "access_token": "string",
  "token_type": "Bearer",
  "expires_in": 3600,
  "refresh_expires_in": 1,
  "not-before-policy": 1,
  "scope": "string"
}
```

使用指定客户端凭据获取新的短期令牌

### 认证

- `Authorization` — _Bearer_ — Bearer 认证，格式为 `Bearer <token>`，其中 token 是你的认证令牌。

### 请求

此端点需要一个对象。

- `grant_type` — _"client_credentials" · required_ — 所请求的授权类型

- `client_id` — _string · optional_ — 客户端标识符

- `client_secret` — _string · optional_ — 客户端密钥

### 响应

访问令牌响应

- `access_token` — _string_ — 访问令牌

- `token_type` — _string_ — 令牌类型（通常为 “Bearer”）

- `expires_in` — _integer · optional_ — 访问令牌的生命周期，单位为秒

- `refresh_expires_in` — _integer · optional_ — 刷新令牌的生命周期

- `not-before-policy` — _integer · optional_ — 强制令牌在指定 unixtime 之前不可使用

- `scope` — _string · optional_ — 访问令牌的 scope

### 错误

400

Bad Request 错误

401

Unauthorized 错误
