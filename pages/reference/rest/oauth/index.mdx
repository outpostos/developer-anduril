# Get OAuth2 token

**Endpoint**: `POST /api/v1/oauth/token`

**cURL**

```bash
curl -X POST https://example.developer.anduril.com/api/v1/oauth/token \
     -H "Authorization: Bearer <token>" \
     -H "Content-Type: application/x-www-form-urlencoded" \
     -d "grant_type=client_credentials"
```

**200 Successful**

```json
{
  "access_token": "string",
  "token_type": "Bearer",
  "expires_in": 3600,
  "refresh_expires_in": 1,
  "not-before-policy": 1,
  "scope": "string"
}
```

Gets a new short-lived token using the specified client credentials

### Authentication

- `Authorization` — _Bearer_ — Bearer authentication of the form `Bearer <token>`, where token is your auth token.

### Request

This endpoint expects an object.

- `grant_type` — _"client_credentials" · required_ — The type of grant being requested

- `client_id` — _string · optional_ — The client identifier

- `client_secret` — _string · optional_ — The client secret

### Response

Access token response

- `access_token` — _string_ — The access token

- `token_type` — _string_ — The type of token (typically “Bearer”)

- `expires_in` — _integer · optional_ — Lifetime of the access token in seconds

- `refresh_expires_in` — _integer · optional_ — Lifetime of the refresh token

- `not-before-policy` — _integer · optional_ — Enforce that a token cannot be used before a specific unixtime

- `scope` — _string · optional_ — The scope of the access token

### Errors

400

Bad Request Error

401

Unauthorized Error
