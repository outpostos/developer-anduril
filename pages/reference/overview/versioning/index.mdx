# 迁移到 v2

Lattice SDK v2 版本代表的是 **SDK 实现** 的变化，而不是底层 Lattice 服务或 API 的变化。

底层 Lattice 服务会继续同时支持 REST 和 gRPC 协议。

如果你是现有 Lattice 开发者，可以从三条迁移路径中选择：

1. [**继续通过 Buf 使用 gRPC**](#option-1-use-v2-with-grpc)（推荐）：如果你的应用使用 gRPC，或已有使用 gRPC 的 Lattice 集成，请直接从 [Lattice Schema Registry](https://schema-registry.developer.anduril.com/anduril/lattice-sdk/sdks/main:protobuf) 获取产物。如果你希望继续使用 gRPC，并希望生成兼容 Lattice SDK v1 的客户端，请在从 Buf 获取产物时使用以下插件版本：插件 | 语言 | 插件版本 | | --- | --- | | C++ | [grpc/cpp@1.68.0](https://buf.build/anduril/lattice-sdk/sdks/main:grpc/cpp?version=v1.68.0) | | Java | [grpc/java@1.54.1](https://buf.build/anduril/lattice-sdk/sdks/main:grpc/java?version=v1.54.1) | | Go | [grpc/go@1.5.1](https://buf.build/anduril/lattice-sdk/sdks/main:grpc/go?version=v1.5.1) | | Javascript/Typescript | [es@2.2.0](https://buf.build/anduril/lattice-sdk/sdks/main:bufbuild/es?version=v2.2.0) | | Python | [betterproto@2.0.0b7](https://github.com/danielgtaylor/python-betterproto/tree/v.2.0.0b7) | | Rust | [neoeinstein-prost@0.5.0](https://buf.build/anduril/lattice-sdk/sdks/main:community/neoeinstein-prost?version=v0.5.0) 和 [neoeinstein-tonic@0.5.0](https://buf.build/anduril/lattice-sdk/sdks/main:community/neoeinstein-tonic?version=v0.5.0) | Python 后续不建议继续使用 `betterproto`，因为该插件不支持 `Any` 类型。对于 Python，建议使用 [`grpc/python`](https://buf.build/anduril/lattice-sdk/sdks/main:grpc/python) 插件。
2. [**迁移到 SDK v2**](#option-2-use-v2-with-rest)（推荐）： 如果你偏好 JSON 格式，或已有 API 使用 REST，建议迁移到基于 REST 的 SDK，以便更快地与 Lattice 集成。REST 提供更简化的设置体验和更好的浏览器兼容性。
3. **继续使用 v1**（不推荐）： 虽然你可以不做更改继续使用基于 gRPC 的 v1 软件包，但不建议采用这种方式。新版 Lattice SDK 包含新功能以及对现有资源的关键更新。

使用下表帮助判断哪条迁移路径最适合你：

|  | REST | gRPC |
| --- | --- | --- |
| 安装 | 通过 [PyPi](https://pypi.org/project/anduril-lattice-sdk/)、[Maven](https://central.sonatype.com/artifact/com.anduril/lattice-sdk)、[npm](https://www.npmjs.com/package/@anduril-industries/lattice-sdk) 获取软件包，或通过 [GitHub](https://github.com/anduril?q=lattice-sdk&type=all&language=&sort=) 获取源码 | 在 [Lattice Schema Registry](https://schema-registry.developer.anduril.com/anduril/lattice-sdk) 中生成软件包 |
| 语言支持 | Python、Typescript、Java 和 Go | 自动生成 16 种语言的绑定 |
| 认证 | 内置支持 OAuth 2.0 | 需要手动管理令牌生命周期 |
| 流式传输 | 支持基础过滤 | 支持高级过滤 |
| API 可用性 | `Entities`、`Tasks` 和 `Objects` | `Entities` 和 `Tasks` |
| 重试 | 对 `5xx`、`408`、`409` 和 `429` 响应内置重试 | 无内置重试，请在你的集成中实现 |
| 传输大小 | JSON 编码的数据包较大 | 二进制编码的数据包较小 |
| 浏览器支持 | 浏览器支持更好 | 浏览器支持较弱 |

以下步骤会引导你完成前两条推荐路径。

## 开始之前

- 检查 Lattice SDK 软件包版本：``` go list -m github.com/anduril/lattice-sdk-go ``` 如果版本以 `1.x.x` 开头，请继续阅读迁移指南：

## 选项 1：通过 gRPC 使用 v2

下面展示如何在 Go 中把 gRPC 实现从 v1 更新到 v2：

1

### 更新 Lattice SDK 依赖

更新 go.mod 文件，加入新版 gRPC 客户端：

```
go get schema-registry.developer.anduril.com/gen/go/anduril/lattice-sdk/grpc/go@v<latest-supported-version>
```

这会从 Lattice Schema Registry 获取指定版本。

2

### 更新 import 语句和实例化方式

更新 import，使其使用新版客户端。下面的 `.diff` 展示了使用 `grpc/go@1.5.1` 所需的变更，这也是 Lattice SDK v1 使用的同一插件版本：

```
--- v1.go
+++ v2.go
@@ -5,7 +5,8 @@ import (
 	"log"
 	"os"

-	entitymanagerv1 "github.com/anduril/lattice-sdk-go/src/anduril/entitymanager/v1"
+	"schema-registry.developer.anduril.com/gen/go/anduril/lattice-sdk/grpc/go/anduril/entitymanager/v1/entitymanagerv1grpc"
+	entitymanagerv1 "schema-registry.developer.anduril.com/gen/go/anduril/lattice-sdk/protocolbuffers/go/anduril/entitymanager/v1"
 	"google.golang.org/grpc"
 	"google.golang.org/grpc/credentials"
 )
@@ -30,15 +31,16 @@ func main() {
 	if err != nil {
 		log.Fatalf("did not connect: %v", err)
 	}
+	defer conn.Close()

-	client := entitymanagerv1.NewEntityManagerAPIClient(conn)
+	client := entitymanagerv1grpc.NewEntityManagerAPIClient(conn)

-	request := &entitymanagerv1.GetEntityRequest{
+	response, err := client.GetEntity(ctx, &entitymanagerv1.GetEntityRequest{
 		EntityId: "<ENTITY_ID>",
-	}
-	response, err := client.GetEntity(ctx, request)
+	})

 	if err != nil {
		log.Fatalf("Error fetching entity: %v", err)
 	}
 	log.Printf("Response: %v", response)
```

## 选项 2：通过 REST 使用 v2

如果你要从 v1 gRPC SDK 迁移到 v2 REST SDK，请按以下步骤更新实现：

1

### 安装 REST SDK

按照 [SDK 设置指南](/guides/getting-started/set-up#get-the-sdk-for-rest) 为你偏好的语言安装 REST SDK。

对于 Go，执行以下命令：

```
go get github.com/anduril/lattice-sdk-go/v2
```

2

### 更新 import 语句和 SDK 用法

从 gRPC 实现迁移到 REST 时，需要更新客户端的初始化和配置方式：

```
--- grpc_v1.go	2025-08-01 10:11:20
+++ rest_v2.go	2025-08-01 12:07:40
@@ -5,39 +5,26 @@

 	"os"

+	"github.com/anduril/lattice-sdk-go/v2/client"
+	"github.com/anduril/lattice-sdk-go/v2/option"
 )

 func main() {
 	ctx := context.Background()
 	latticeEndpoint := os.Getenv("LATTICE_ENDPOINT")

 		log.Fatalf("Missing required environment variables")
 	}
-	auth := &BearerTokenAuth{
-		Token: environmentToken,
-	}

-		grpc.WithPerRPCCredentials(auth),
-	}
-	conn, err := grpc.NewClient(latticeEndpoint, opts...)
-	if err != nil {
-		log.Fatalf("did not connect: %v", err)
-	}
+	client := client.NewClient(
+		option.WithToken(environmentToken),
+		option.WithBaseURL(latticeEndpoint),
+	)

-	client := entitymanagerv1.NewEntityManagerAPIClient(conn)
+	response, err := client.Entities.GetEntity(ctx, "<ENTITY_ID>")

-	request := &entitymanagerv1.GetEntityRequest{
-		EntityId: "<ENTITY_ID>",
-	}
-	response, err := client.GetEntity(ctx, request)

 		log.Fatalf("Error fetching entity: %v", err)
 	}
```
