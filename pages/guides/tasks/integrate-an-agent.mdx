# 集成 agent

**可任务化 agent** 是一个资产或一组资产，它会监听 Lattice 中分配给自己的任务、执行任务，并回报进度。本指南介绍完整 agent 工作流：发布可任务化 agent、流式接收并解析已分配任务、更新任务状态，以及处理取消请求。

agent 调用下列 API 来监听 Lattice 中分配给自己的任务：

- StreamAsAgent - 使用 REST 监控路由到 agent 的任务。
- ListenAsAgent - 使用 gRPC 监控路由到 agent 的任务。

## 开始之前

- 要发布可任务化实体并订阅任务，请设置 Lattice 环境。
- 熟悉实体和不同实体类型。
- 复习如何定义任务。本指南使用该页中的 Objective 任务定义作为示例。

gRPC 认证

如果你将 gRPC 与客户端凭证一起使用，请在运行本页示例前[设置令牌刷新模块](/guides/getting-started/authenticate#using-grpc)。

## 发布可任务化 agent

*资产*是由你控制，或由其他操作员或系统控制的实体。资产可以接受搜索或跟踪等任务。*agent* 是一个资产或一组资产，可以完成一组特定的已定义任务。

要发布 agent，请执行以下操作：

1

### 定义 `TaskCatalog`

实体模型的 [`TaskCatalog`](/reference/rest/entities/publish-entity#request.body.taskCatalog) 组件定义资产可以执行的任务。

例如，如果你的资产支持 [`Objective`](/guides/tasks/define-a-task) 任务，请发布一个在目录中包含该任务的资产实体，并监听和执行该任务。`taskSpecificationUrl` 是你编写并发布到 Schema Registry 的任务定义类型 URL：

```
  "taskCatalog": {
      // Define the tasks the asset can perform.
      "taskDefinitions": [
          {
              // Set the task specification URL to your Objective definition.
              "taskSpecificationUrl": "type.googleapis.com/org.example.reconnaissance.v1beta.Objective",
          }
      ]
  }
```

2

### 发布 agent

使用 [`PublishEntity`](/reference/rest/entities/publish-entity) 方法发布可任务化 agent：

```
package main

import (
	"context"
	"fmt"
	"net/http"
	"os"
	"time"

	Lattice "github.com/anduril/lattice-sdk-go/v4"
	"github.com/anduril/lattice-sdk-go/v4/client"
	"github.com/anduril/lattice-sdk-go/v4/option"
	"github.com/google/uuid"
)

func main() {
	// Get environment variables
	latticeEndpoint := os.Getenv("LATTICE_ENDPOINT")
	clientSecret := os.Getenv("LATTICE_CLIENT_SECRET")
	clientId := os.Getenv("LATTICE_CLIENT_ID")

	// Remove sandboxesToken from the following statements if you are not developing on Sandboxes
	sandboxesToken := os.Getenv("SANDBOXES_TOKEN")

	// Check required environment variables
	if latticeEndpoint == "" || clientId == "" || clientSecret == "" || sandboxesToken == "" {
		fmt.Println("Missing required environment variables")
		os.Exit(1)
	}

	// Initialize headers for sandbox authorization
	headers := http.Header{}
	headers.Add("Anduril-Sandbox-Authorization", fmt.Sprintf("Bearer %s", sandboxesToken))

	// Create the client
	LatticeClient := client.NewClient(
		option.WithClientCredentials(clientId, clientSecret),
		option.WithBaseURL(fmt.Sprintf("https://%s", latticeEndpoint)),
		option.WithHTTPHeader(headers),
	)

	// Generate a unique ID for the entity
	entityId := uuid.New().String()

	// Get creation time
	creationTime := time.Now().UTC()

	// Continuously publish the entity
	for {
		latestTimestamp := time.Now().UTC()
		ctx := context.Background()

		// Create entity to publish
		entity := Lattice.Entity{
			EntityID:    &entityId,
			Description: Lattice.String("Friendly drone asset"),
			Aliases: &Lattice.Aliases{
				Name: Lattice.String("Drone 1"),
			},
			IsLive:      Lattice.Bool(true),
			CreatedTime: Lattice.Time(creationTime),
			ExpiryTime:  Lattice.Time(latestTimestamp.Add(1 * time.Minute)),
			Ontology: &Lattice.Ontology{
				Template:     Lattice.OntologyTemplateTemplateAsset.Ptr(),
				PlatformType: Lattice.String("UAV"),
			},
			MilView: &Lattice.MilView{
				Disposition: Lattice.MilViewDispositionDispositionFriendly.Ptr(),
				Environment: Lattice.MilViewEnvironmentEnvironmentAir.Ptr(),
			},
			Location: &Lattice.Location{
				Position: &Lattice.Position{
					LatitudeDegrees:   Lattice.Float64(50.91402185768586),
					LongitudeDegrees:  Lattice.Float64(0.79203612077257),
					AltitudeAsfMeters: Lattice.Float64(1000),
				},
			},
			Provenance: &Lattice.Provenance{
				IntegrationName:  Lattice.String("your_integration_name"),
				DataType:         Lattice.String("your_data_type"),
				SourceUpdateTime: Lattice.Time(latestTimestamp),
			},
			Health: &Lattice.Health{
				ConnectionStatus: Lattice.HealthConnectionStatusConnectionStatusOnline.Ptr(),
				HealthStatus:     Lattice.HealthHealthStatusHealthStatusHealthy.Ptr(),
				UpdateTime:       Lattice.Time(latestTimestamp),
			},
			TaskCatalog: &Lattice.TaskCatalog{
				TaskDefinitions: []*Lattice.TaskDefinition{
					{TaskSpecificationURL: Lattice.String("type.googleapis.com/anduril.tasks.v2.VisualId")},
					{TaskSpecificationURL: Lattice.String("type.googleapis.com/anduril.tasks.v2.Investigate")},
				},
			},
		}

		// Publish the entity
		_, err := LatticeClient.Entities.PublishEntity(ctx, &entity)

		// Handle errors
		if err != nil {
			fmt.Printf("Error publishing entity: %v\n", err)
		} else {
			fmt.Println("Published asset: " + entityId)
		}

		// Wait before next request
		time.Sleep(5 * time.Second)
	}
}
```

如果成功，你会在控制台中看到实体 ID：

```
2025-07-16T02:50:04.694Z [INFO]: Published asset: <entity-id>
```

## 处理已分配任务

agent 发布后，集成应打开一个流以接收路由给它的任务。每个任务都携带 [`specification`](/reference/rest/tasks/create-task#request.body.specification)，即保存任务数据的 [`google.protobuf.Any`](/guides/tasks/define-a-task#define-a-custom-schema)。要执行任务，agent 会从请求中读取元数据，然后将 specification 解码为它在目录中公开的任务类型。

1

### 以 agent 身份流式传输任务

使用 [`StreamAsAgent`](/reference/rest/tasks/stream-as-agent) 打开流；如果使用 gRPC，则使用 [ListenAsAgent](/reference/grpc/taskmanager-v1/listen-as-agent)。当 `executeRequest` 到达时，agent 会读取任务 ID 和状态版本、解析任务数据，然后上报它已经开始任务。

通过流投递任务不会等待 agent 确认收到，因此静默断开的连接可能导致 agent 悄悄跳过任务。要获得连接仍然存活的正向信号，请在打开流时设置 `heartbeatIntervalMs`：

- `heartbeatIntervalMs` _Number_
  Lattice 在流上发送 heartbeat 事件的间隔，单位为毫秒。对于 `StreamAsAgent`，默认值为 30000 ms，最小值为 1000 ms；更小的值会提升为 1000 ms。对于 `ListenAsAgent`，除非设置该字段，否则 heartbeat 默认禁用。

设置后，Lattice 会按指定间隔发送 heartbeat，agent 可以将缺失 heartbeat 视为连接断开并重新连接。Heartbeat 与任务请求在同一流上到达，且只携带时间戳，因此接收循环会跳过它们，而不是将其视为任务。

将 `AGENT_ID` 替换为你要分配任务的 agent ID。如果你在 Sandboxes 上开发，请将其替换为以下模拟资产：`Demo-Sim-Asset1`：

```
package main

import (
	"context"
	"errors"
	"fmt"
	"io"
	"log"
	"net/http"
	"os"
	"time"

	Lattice "github.com/anduril/lattice-sdk-go/v4"
	"github.com/anduril/lattice-sdk-go/v4/client"
	"github.com/anduril/lattice-sdk-go/v4/option"
)

// Type URL of the Objective task defined in objective.proto.
const objectiveType = "type.googleapis.com/org.example.reconnaissance.v1beta.Objective"

// parseObjective parses the Objective carried in the task's specification. Over
// REST, the specification is a google.protobuf.Any represented as JSON: a Type
// URL alongside the task's flattened fields, which the SDK surfaces as
// ExtraProperties.
func parseObjective(specification *Lattice.GoogleProtobufAny) {
	if specification == nil || specification.Type == nil || *specification.Type != objectiveType {
		log.Printf("Unsupported task type: %v", specification.GetType())
		return
	}

	// Objective is a oneof: read whichever target the operator set.
	fields := specification.ExtraProperties
	if entityID, ok := fields["entityId"].(string); ok && entityID != "" {
		log.Printf("  Objective: entity %s", entityID)
	} else if lla, ok := fields["lla"].(map[string]interface{}); ok {
		log.Printf("  Objective: LLA (lat %v, lon %v, alt %vm)",
			lla["latitudeDegrees"], lla["longitudeDegrees"], lla["altitudeHaeM"])
	} else {
		log.Printf("  Objective: no target set")
	}
}

func main() {
	// Get environment variables
	latticeEndpoint := os.Getenv("LATTICE_ENDPOINT")
	clientSecret := os.Getenv("LATTICE_CLIENT_SECRET")
	clientId := os.Getenv("LATTICE_CLIENT_ID")
	sandboxesToken := os.Getenv("SANDBOXES_TOKEN")

	// Check required environment variables
	if latticeEndpoint == "" || clientId == "" || clientSecret == "" || sandboxesToken == "" {
		fmt.Println("Missing required environment variables")
		os.Exit(1)
	}

	// Initialize headers for sandbox authorization
	headers := http.Header{}
	headers.Add("Anduril-Sandbox-Authorization", fmt.Sprintf("Bearer %s", sandboxesToken))
	// Create the client
	LatticeClient := client.NewClient(
		option.WithClientCredentials(clientId, clientSecret),
		option.WithBaseURL(fmt.Sprintf("https://%s", latticeEndpoint)),
		option.WithHTTPHeader(headers),
	)

	// Set the entity ID to listen for tasks
	entityId := "<AGENT_ID>"
	fmt.Printf("Streaming tasks for entity %s...\n", entityId)

	// Create context for the request
	ctx := context.Background()

	// Create agent stream request. Set HeartbeatIntervalMs so Lattice sends
	// periodic heartbeats; a missing heartbeat signals a dropped connection.
	heartbeatIntervalMs := 30000
	agentStreamRequest := Lattice.AgentStreamRequest{
		AgentSelector: &Lattice.EntityIDsSelector{
			EntityIDs: []string{entityId},
		},
		HeartbeatIntervalMs: &heartbeatIntervalMs,
	}

	// Stream tasks
	stream, err := LatticeClient.Tasks.StreamAsAgent(ctx, &agentStreamRequest)
	if err != nil {
		fmt.Printf("Error streaming tasks: %v\n", err)
		os.Exit(1)
	}

	// Process stream events
	for {
		select {
		case <-ctx.Done():
			log.Printf("Context canceled: %v", ctx.Err())
			return
		default:
			// Continue processing
		}

		event, err := stream.Recv()

		if errors.Is(err, io.EOF) {
			log.Println("Stream completed successfully.")
			return
		}

		if err != nil {
			log.Printf("Error receiving message: %v", err)
			continue
		}

		if event.Event == "heartbeat" {
			timestamp := *event.Heartbeat.Timestamp
			log.Printf("Heartbeat: %s", timestamp)
		} else {
			request := event.GetAgentRequest()
			if executeRequest := request.GetExecuteRequest(); executeRequest != nil {
				task := executeRequest.GetTask()
				if task != nil {
					taskId := *task.GetVersion().GetTaskID()
					taskStatusVersion := *task.GetVersion().GetStatusVersion()
					description := *task.GetDescription()

					log.Printf("Starting task %s, version %d: %s", taskId, taskStatusVersion, description)

					// Parse the Objective the operator sent with the task.
					parseObjective(task.GetSpecification())

					// Update task status to STATUS_EXECUTING
					result, err := startTask(ctx, LatticeClient, taskId, int(taskStatusVersion), entityId)
					if err != nil {
						log.Printf("Error starting task: %v", err)
						continue
					}

					log.Printf("Started task with status version: %d", *result.StatusVersion)
				}
			} else if completeRequest := request.GetCompleteRequest(); completeRequest != nil {
				taskToComplete := completeRequest.GetTaskID()
				if taskToComplete != nil {
					log.Printf("Completing task: %s", *taskToComplete)
				}
			} else if cancelRequest := request.GetCancelRequest(); cancelRequest != nil {
				taskToCancel := cancelRequest.GetTaskID()
				if taskToCancel != nil {
					log.Printf("Cancelling task: %s", *taskToCancel)
				}
			}
		}

		// Sleep briefly to prevent tight looping
		time.Sleep(100 * time.Millisecond)
	}
}

// startTask updates the task status to STATUS_EXECUTING
func startTask(ctx context.Context, client *client.Client, taskId string, taskStatusVersion int, agentEntityId string) (*Lattice.TaskVersion, error) {
	// Increment status version for the update
	taskStatusVersion++

	// Create system principal with the agent entity ID
	principal := Lattice.Principal{
		System: &Lattice.System{
			EntityID: &agentEntityId,
		},
	}

	taskStatus := Lattice.TaskStatus{
		Status: Lattice.TaskStatusStatusStatusExecuting.Ptr(),
	}

	// Create task status update request
	taskStatusUpdate := Lattice.TaskStatusUpdate{
		TaskID:        taskId,
		StatusVersion: &taskStatusVersion,
		NewStatus:     &taskStatus,
		Author:        &principal,
	}

	// Call the UpdateTaskStatus API
	task, err := client.Tasks.UpdateTaskStatus(ctx, &taskStatusUpdate)
	if err != nil {
		return nil, fmt.Errorf("error updating task status: %w", err)
	}

	return task.Version, nil
}
```

如果成功，你会看到以下输出：

```
Listening for tasks for entity with ID <entity-id>...
```

agent 还应优雅处理流中断。如果与 Lattice 的连接失败，流会关闭。请处理流错误并重新连接，确保 agent 在瞬时网络问题期间仍保持对任务更新的订阅。

更多信息请参阅[重试连接](/guides/best-practices/retry-connections)。

该示例会在任务到达时立即上报 `STATUS_EXECUTING`，但 agent 并不必须接受每个任务。

执行任务前，请验证 agent 确实能够执行该任务，例如请求参数是否在其能力范围内。如果不能，agent 可以不上报开始执行，而是通过上报 `STATUS_DONE_NOT_OK` 并附带 `ERROR_CODE_REJECTED` 的 [`TaskError`](/reference/rest/tasks/update-task-status#request.body.newStatus.taskError) 来拒绝任务。

2

### 解析任务 specification

## 分配任务并验证任务处理器

下列步骤不是实现任务功能所必需的；它们展示如何在开发环境中端到端运行任务处理器。将任务分配给 agent，然后确认它能接收、解析并更新任务。

1

### 使用 UI 分配任务

在大多数情况下，操作员使用 Lattice UI 为 agent 分配任务。要在 Lattice Sandboxes 中测试 agent 的任务处理器，请执行以下操作：

1. 打开环境的 Lattice UI，并从 Assets 面板选择一个资产。在 Sandboxes 上，选择 Demo-Sim-Asset1。
2. 在实体窗格中选择 Task，然后选择 Objective 任务。
3. 在右侧 Task Details 面板中设置 objective，可以是要侦察的实体，也可以是纬度/经度/高度点，然后选择 Execute Task。这与你的 agent 从任务 specification 中读取的字段相同。

2

### 验证任务状态

如果成功，你会在本地开发控制台中看到已解析任务数据和更新后的状态版本：

```
Starting task <task-id>, version 1: Reconnaissance objective
  Objective: LLA (lat 37.7749, lon -122.4194, alt 100.0m)
Started task with status version: 2.
```

agent 已成功解析任务数据、更新任务状态，并递增任务状态版本。

## 更新任务状态

随着 agent 推进任务，它会通过 [`UpdateTaskStatus`](/reference/rest/tasks/update-task-status) 向 Lattice 上报实时更新，并在每次更新时递增任务的 `statusVersion`。在 Lattice 中，任务会经过下列状态：

1

### `STATUS_SENT`

Lattice 向 agent 发送任务时，会自动从 `STATUS_SENT` 开始：

```
"task": {
    "version": {
        "taskId": "my-task",
        "definitionVersion": 1,
        "statusVersion": 1
    },
    "status": {
        "status": "STATUS_SENT"
    }
}
```

2

### `STATUS_MACHINE_RECEIPT`

然后 agent 以 `STATUS_MACHINE_RECEIPT` 状态响应，表示任务已收到，并相应递增 `statusVersion`：

```
"statusUpdate": {
    "version": {
        "taskId": "my-task",
        "definitionVersion": 1,
        "statusVersion": 2
    },
    "status": {
        "status": "STATUS_MACHINE_RECEIPT"
    }
}
```

3

### `STATUS_ACK`

当 agent 准备确认任务时，会使用 `STATUS_ACK` 完成确认，并再次递增 `statusVersion`：

```
"statusUpdate": {
    "version": {
        "taskId": "my-task",
        "definitionVersion": 1,
        "statusVersion": 3
    },
    "status": {
        "status": "STATUS_ACK"
    }
}
```

4

### `STATUS_WILCO`

agent 使用 `STATUS_WILCO` 确认它打算执行任务：

```
"statusUpdate": {
    "version": {
        "taskId": "my-task",
        "definitionVersion": 1,
        "statusVersion": 4
    },
    "status": {
        "status": "STATUS_WILCO"
    }
}
```

5

### `STATUS_EXECUTING`

当 agent 开始主动执行任务时，会通过向 Lattice 上报 `STATUS_EXECUTING` 来表示这一点：

```
"statusUpdate": {
    "version": {
        "taskId": "my-task",
        "definitionVersion": 1,
        "statusVersion": 5
    },
    "status": {
        "status": "STATUS_EXECUTING"
    }
}
```

6

### `STATUS_DONE_OK`

最后，当 agent 达到终止状态并成功完成任务时，会上报 `STATUS_DONE_OK`。agent 可以自行达到该状态，例如其逻辑判定任务目标已满足；也可以响应操作员发起的任务完成请求而达到该状态：

```
"statusUpdate": {
    "version": {
        "taskId": "my-task",
        "definitionVersion": 1,
        "statusVersion": 6
    },
    "status": {
        "status": "STATUS_DONE_OK"
    }
}
```

7

### `STATUS_DONE_NOT_OK`

如果 agent 达到终止状态但未成功完成任务，则会上报 `STATUS_DONE_NOT_OK`。agent 可以自行达到该状态，例如其逻辑判定任务无法完成；也可以响应操作员发起的任务完成或取消请求而达到该状态。上报 `STATUS_DONE_NOT_OK` 时，agent 应包含描述性的 [`TaskError`](/reference/rest/tasks/update-task-status#request.body.newStatus.taskError)：

```
"statusUpdate": {
    "version": {
        "taskId": "my-task",
        "definitionVersion": 1,
        "statusVersion": 7
    },
    "status": {
        "status": "STATUS_DONE_NOT_OK",
        "taskError": {
        "code": "ERROR_CODE_FAILED",
        "message": "The asset failed task execution due to an internal error.",
        }
    }
}
```

在此示例中，消息表示 agent 在任务执行期间遇到内部错误。你可以添加更具描述性的错误，帮助操作员相应地排查问题。

`STATUS_DONE_OK` 和 `STATUS_DONE_NOT_OK` 状态被视为终止状态。任务一旦达到任一状态，即表示完成且无法再更新。

## 处理任务取消

操作员可以在 agent 执行任务时请求取消任务。当任务已经发送给 agent 后，Lattice 会将 [`CancelTask`](/reference/rest/tasks/cancel-task) 请求路由给该 agent，由它决定接受还是拒绝。有关此工作流的操作员侧，请参阅[取消任务](/guides/tasks/command-and-operate#cancel-tasks)。

1

### 设置任务处理器

创建一个任务处理器，用于监听分配给 agent 的任务并处理取消请求。为了演示，此示例使用 `TASK_ACTIVE` 环境变量控制 agent 接受还是拒绝取消：

```
package main

import (
	"context"
	"errors"
	"fmt"
	"io"
	"log"
	"net/http"
	"os"
	"strings"
	"time"

	Lattice "github.com/anduril/lattice-sdk-go/v4"
	"github.com/anduril/lattice-sdk-go/v4/client"
	"github.com/anduril/lattice-sdk-go/v4/option"
)

// Sets whether the task is currently being processed. If so, it cannot be cancelled.
var taskActive bool

func main() {
	// Get environment variables
	latticeEndpoint := os.Getenv("LATTICE_ENDPOINT")
	clientSecret := os.Getenv("LATTICE_CLIENT_SECRET")
	clientId := os.Getenv("LATTICE_CLIENT_ID")
	sandboxesToken := os.Getenv("SANDBOXES_TOKEN")
	taskActiveStr := os.Getenv("TASK_ACTIVE")

	// Check required environment variables
	if latticeEndpoint == "" || clientId == "" || clientSecret == "" || sandboxesToken == "" {
		fmt.Println("Missing required environment variables")
		os.Exit(1)
	}

	// Parse TASK_ACTIVE environment variable
	taskActive = strings.ToLower(taskActiveStr) == "true"

	// Initialize headers for sandbox authorization
	headers := http.Header{}
	headers.Add("Anduril-Sandbox-Authorization", fmt.Sprintf("Bearer %s", sandboxesToken))

	// Create the client
	LatticeClient := client.NewClient(
		option.WithClientCredentials(clientId, clientSecret),
		option.WithBaseURL(fmt.Sprintf("https://%s", latticeEndpoint)),
		option.WithHTTPHeader(headers),
	)

	// Set the entity ID to listen for tasks
	entityId := "<AGENT_ID>"
	fmt.Printf("Streaming tasks for entity: %s...\n", entityId)

	// Create context for the request
	ctx := context.Background()

	// Create agent stream request
	agentStreamRequest := Lattice.AgentStreamRequest{
		AgentSelector: &Lattice.EntityIDsSelector{
			EntityIDs: []string{entityId},
		},
	}

	// Stream tasks
	stream, err := LatticeClient.Tasks.StreamAsAgent(ctx, &agentStreamRequest)
	if err != nil {
		fmt.Printf("Error streaming tasks: %v\n", err)
		os.Exit(1)
	}

	// Process stream events
	for {
		select {
		case <-ctx.Done():
			log.Printf("Context canceled: %v", ctx.Err())
			return
		default:
			// Continue processing
		}

		event, err := stream.Recv()

		if errors.Is(err, io.EOF) {
			log.Println("Stream completed successfully.")
			return
		}

		if err != nil {
			log.Printf("Error receiving message: %v", err)
			continue
		}

		if event.Event == "heartbeat" {
			timestamp := *event.Heartbeat.Timestamp
			log.Printf("Heartbeat: %s", timestamp)
		} else {
			request := event.GetAgentRequest()
			if executeRequest := request.GetExecuteRequest(); executeRequest != nil {
				task := executeRequest.GetTask()
				if task != nil {
					taskId := *task.GetVersion().GetTaskID()
					taskStatusVersion := *task.GetVersion().GetStatusVersion()
					description := *task.GetDescription()

					log.Printf("Starting task %s, version %d: %s", taskId, taskStatusVersion, description)

					// Update task status to STATUS_EXECUTING
					result, err := executeTask(ctx, LatticeClient, taskId, int(taskStatusVersion), entityId)
					if err != nil {
						log.Printf("Error starting task: %v", err)
						continue
					}

					log.Printf("Started task with status version: %d", *result.StatusVersion)
				}
			} else if completeRequest := request.GetCompleteRequest(); completeRequest != nil {
				taskToComplete := completeRequest.GetTaskID()
				if taskToComplete != nil {
					log.Printf("Completing task: %s", *taskToComplete)
					err := completeTask(ctx, LatticeClient, *taskToComplete, entityId)
					if err != nil {
						log.Printf("Error completing task: %v", err)
					}
				}
			} else if cancelRequest := request.GetCancelRequest(); cancelRequest != nil {
				taskToCancel := cancelRequest.GetTaskID()
				if taskToCancel != nil {
					log.Printf("Cancelling task: %s", *taskToCancel)
					err := cancelTask(ctx, LatticeClient, *taskToCancel, entityId)
					if err != nil {
						log.Printf("Error cancelling task: %v", err)
					}
				}
			}
		}

		// Sleep briefly to prevent tight looping
		time.Sleep(100 * time.Millisecond)
	}
}

// executeTask updates the task status to STATUS_EXECUTING
func executeTask(ctx context.Context, client *client.Client, taskId string, taskStatusVersion int, agentEntityId string) (*Lattice.TaskVersion, error) {
	// Increment status version for the update
	taskStatusVersion++

	// Create system principal with the agent entity ID
	principal := Lattice.Principal{
		System: &Lattice.System{
			EntityID: &agentEntityId,
		},
	}

	taskStatus := Lattice.TaskStatus{
		Status: Lattice.TaskStatusStatusStatusExecuting.Ptr(),
	}

	// Create task status update request
	taskStatusUpdate := Lattice.TaskStatusUpdate{
		TaskID:        taskId,
		StatusVersion: &taskStatusVersion,
		NewStatus:     &taskStatus,
		Author:        &principal,
	}

	// Call the UpdateTaskStatus API
	task, err := client.Tasks.UpdateTaskStatus(ctx, &taskStatusUpdate)
	if err != nil {
		return nil, fmt.Errorf("error updating task status: %w", err)
	}

	return task.Version, nil
}

// cancelTask handles cancellation requests from Lattice
func cancelTask(ctx context.Context, client *client.Client, taskId string, entityId string) error {
	// Get current task to retrieve status_version
	getTaskRequest := Lattice.GetTaskRequest{
		TaskID: taskId,
	}
	task, err := client.Tasks.GetTask(ctx, &getTaskRequest)
	if err != nil {
		return fmt.Errorf("error getting task: %w", err)
	}
	if task.Status == nil || task.Version == nil || task.Version.StatusVersion == nil {
		return fmt.Errorf("task status or version is missing")
	}
	currentTaskStatus := task.Status.Status
	taskStatusVersion := *task.Version.StatusVersion
	taskStatusVersion++

	// Create system principal with the agent entity ID
	principal := Lattice.Principal{
		System: &Lattice.System{
			EntityID: &entityId,
		},
	}

	if taskActive {
		// Reject cancellation: task is active and cannot be cancelled
		rejectedMessage := "Task is already active, and cannot be cancelled."
		taskStatus := Lattice.TaskStatus{
			// Because the cancellation is being rejected, we do not
			// change the task status.
			Status: currentTaskStatus,
			TaskError: &Lattice.TaskError{
				Code:    Lattice.TaskErrorCodeErrorCodeRejected.Ptr(),
				Message: &rejectedMessage,
			},
		}

		taskStatusUpdate := Lattice.TaskStatusUpdate{
			TaskID:        taskId,
			StatusVersion: &taskStatusVersion,
			NewStatus:     &taskStatus,
			Author:        &principal,
		}

		_, err := client.Tasks.UpdateTaskStatus(ctx, &taskStatusUpdate)
		if err != nil {
			return fmt.Errorf("error updating task status: %w", err)
		}

		log.Println("Task could not be cancelled.")
	} else {
		// Accept cancellation
		cancelledMessage := "Task cancelled by agent."
		taskStatus := Lattice.TaskStatus{
			Status: Lattice.TaskStatusStatusStatusDoneNotOk.Ptr(),
			TaskError: &Lattice.TaskError{
				Code:    Lattice.TaskErrorCodeErrorCodeCancelled.Ptr(),
				Message: &cancelledMessage,
			},
		}

		taskStatusUpdate := Lattice.TaskStatusUpdate{
			TaskID:        taskId,
			StatusVersion: &taskStatusVersion,
			NewStatus:     &taskStatus,
			Author:        &principal,
		}

		_, err := client.Tasks.UpdateTaskStatus(ctx, &taskStatusUpdate)
		if err != nil {
			return fmt.Errorf("error updating task status: %w", err)
		}

		log.Println("Task has been cancelled.")
	}

	return nil
}

// completeTask updates the task status to STATUS_DONE_OK
func completeTask(ctx context.Context, client *client.Client, taskId string, entityId string) error {
	// Get current task to retrieve status_version
	getTaskRequest := Lattice.GetTaskRequest{
		TaskID: taskId,
	}

		return fmt.Errorf("error getting task: %w", err)

		return fmt.Errorf("task version is missing")
	}

	// Increment version and update to terminal state
	taskStatusVersion++

	// Create system principal with the agent entity ID
	principal := Lattice.Principal{
		System: &Lattice.System{
			EntityID: &entityId,
		},
	}

	taskStatus := Lattice.TaskStatus{
		Status: Lattice.TaskStatusStatusStatusDoneOk.Ptr(),
	}

	taskStatusUpdate := Lattice.TaskStatusUpdate{
		TaskID:        taskId,
		StatusVersion: &taskStatusVersion,
		NewStatus:     &taskStatus,
		Author:        &principal,
	}

	_, err = client.Tasks.UpdateTaskStatus(ctx, &taskStatusUpdate)
	if err != nil {
		return fmt.Errorf("error updating task status: %w", err)
	}

	return nil
}
```

[`StreamAsAgent`](/reference/rest/tasks/stream-as-agent) API 会建立 server-sent events (SSE) 流，用于投递三类请求：通知 agent 开始执行任务的 **`executeRequest`**，请求 agent 完成任务的 **`completeRequest`**，以及请求 agent 取消任务的 **`cancelRequest`**。

```
	headers.Add("Anduril-Sandbox-Authorization", fmt.Sprintf("Bearer %s", sandboxesToken))

	// Create the client
	LatticeClient := client.NewClient(
		option.WithClientCredentials(clientId, clientSecret),
		option.WithBaseURL(fmt.Sprintf("https://%s", latticeEndpoint)),
		option.WithHTTPHeader(headers),
	)

	// Set the entity ID to listen for tasks
	entityId := "<AGENT_ID>"
	fmt.Printf("Streaming tasks for entity: %s...\n", entityId)

	// Create context for the request
	ctx := context.Background()

	// Create agent stream request
	agentStreamRequest := Lattice.AgentStreamRequest{
		AgentSelector: &Lattice.EntityIDsSelector{
			EntityIDs: []string{entityId},
		},
	}

	// Stream tasks
	stream, err := LatticeClient.Tasks.StreamAsAgent(ctx, &agentStreamRequest)
	if err != nil {
		fmt.Printf("Error streaming tasks: %v\n", err)
		os.Exit(1)
	}

	// Process stream events
	for {
		select {
		case <-ctx.Done():
			log.Printf("Context canceled: %v", ctx.Err())
			return
		default:
			// Continue processing
		}

		event, err := stream.Recv()

		if errors.Is(err, io.EOF) {
			log.Println("Stream completed successfully.")
			return
		}

		if err != nil {
			log.Printf("Error receiving message: %v", err)
			continue
		}

		if event.Event == "heartbeat" {
			timestamp := *event.Heartbeat.Timestamp
			log.Printf("Heartbeat: %s", timestamp)
		} else {
			request := event.GetAgentRequest()
			if executeRequest := request.GetExecuteRequest(); executeRequest != nil {
				task := executeRequest.GetTask()
				if task != nil {
					taskId := *task.GetVersion().GetTaskID()
					taskStatusVersion := *task.GetVersion().GetStatusVersion()
					description := *task.GetDescription()

					log.Printf("Starting task %s, version %d: %s", taskId, taskStatusVersion, description)

					// Update task status to STATUS_EXECUTING
					result, err := executeTask(ctx, LatticeClient, taskId, int(taskStatusVersion), entityId)
					if err != nil {
						log.Printf("Error starting task: %v", err)
						continue
					}

					log.Printf("Started task with status version: %d", *result.StatusVersion)
				}
			} else if completeRequest := request.GetCompleteRequest(); completeRequest != nil {
				taskToComplete := completeRequest.GetTaskID()
				if taskToComplete != nil {
					log.Printf("Completing task: %s", *taskToComplete)
					err := completeTask(ctx, LatticeClient, *taskToComplete, entityId)
					if err != nil {
						log.Printf("Error completing task: %v", err)
					}
				}
			} else if cancelRequest := request.GetCancelRequest(); cancelRequest != nil {
				taskToCancel := cancelRequest.GetTaskID()
				if taskToCancel != nil {
					log.Printf("Cancelling task: %s", *taskToCancel)
					err := cancelTask(ctx, LatticeClient, *taskToCancel, entityId)
					if err != nil {
						log.Printf("Error cancelling task: %v", err)
					}
				}
			}
		}

		// Sleep briefly to prevent tight looping
		time.Sleep(100 * time.Millisecond)
	}
}

// executeTask updates the task status to STATUS_EXECUTING
func executeTask(ctx context.Context, client *client.Client, taskId string, taskStatusVersion int, agentEntityId string) (*Lattice.TaskVersion, error) {
	// Increment status version for the update
	taskStatusVersion++

	// Create system principal with the agent entity ID
	principal := Lattice.Principal{
		System: &Lattice.System{
			EntityID: &agentEntityId,
		},
	}

	taskStatus := Lattice.TaskStatus{
		Status: Lattice.TaskStatusStatusStatusExecuting.Ptr(),
	}

	// Create task status update request
	taskStatusUpdate := Lattice.TaskStatusUpdate{
		TaskID:        taskId,
		StatusVersion: &taskStatusVersion,
		NewStatus:     &taskStatus,
		Author:        &principal,
	}

	// Call the UpdateTaskStatus API
	task, err := client.Tasks.UpdateTaskStatus(ctx, &taskStatusUpdate)
	if err != nil {
		return nil, fmt.Errorf("error updating task status: %w", err)
	}

	return task.Version, nil
}

// cancelTask handles cancellation requests from Lattice
func cancelTask(ctx context.Context, client *client.Client, taskId string, entityId string) error {
	// Get current task to retrieve status_version
	getTaskRequest := Lattice.GetTaskRequest{
		TaskID: taskId,
	}
	task, err := client.Tasks.GetTask(ctx, &getTaskRequest)
	if err != nil {
		return fmt.Errorf("error getting task: %w", err)
	}
	if task.Status == nil || task.Version == nil || task.Version.StatusVersion == nil {
		return fmt.Errorf("task status or version is missing")
	}
	currentTaskStatus := task.Status.Status
	taskStatusVersion := *task.Version.StatusVersion
	taskStatusVersion++

	// Create system principal with the agent entity ID
	principal := Lattice.Principal{
		System: &Lattice.System{
			EntityID: &entityId,
		},
	}

	if taskActive {
		// Reject cancellation: task is active and cannot be cancelled
		rejectedMessage := "Task is already active, and cannot be cancelled."
		taskStatus := Lattice.TaskStatus{
			// Because the cancellation is being rejected, we do not
			// change the task status.
			Status: currentTaskStatus,
			TaskError: &Lattice.TaskError{
				Code:    Lattice.TaskErrorCodeErrorCodeRejected.Ptr(),
				Message: &rejectedMessage,
			},
		}

		taskStatusUpdate := Lattice.TaskStatusUpdate{
			TaskID:        taskId,
			StatusVersion: &taskStatusVersion,
			NewStatus:     &taskStatus,
			Author:        &principal,
		}

		_, err := client.Tasks.UpdateTaskStatus(ctx, &taskStatusUpdate)
		if err != nil {
			return fmt.Errorf("error updating task status: %w", err)
		}

		log.Println("Task could not be cancelled.")
	} else {
		// Accept cancellation
		cancelledMessage := "Task cancelled by agent."
		taskStatus := Lattice.TaskStatus{
			Status: Lattice.TaskStatusStatusStatusDoneNotOk.Ptr(),
			TaskError: &Lattice.TaskError{
				Code:    Lattice.TaskErrorCodeErrorCodeCancelled.Ptr(),
				Message: &cancelledMessage,
			},
		}

		taskStatusUpdate := Lattice.TaskStatusUpdate{
			TaskID:        taskId,
			StatusVersion: &taskStatusVersion,
			NewStatus:     &taskStatus,
			Author:        &principal,
		}

		_, err := client.Tasks.UpdateTaskStatus(ctx, &taskStatusUpdate)
		if err != nil {
			return fmt.Errorf("error updating task status: %w", err)
		}

		log.Println("Task has been cancelled.")
	}

	return nil
}

// completeTask updates the task status to STATUS_DONE_OK
func completeTask(ctx context.Context, client *client.Client, taskId string, entityId string) error {
	// Get current task to retrieve status_version
	getTaskRequest := Lattice.GetTaskRequest{
		TaskID: taskId,
	}
	task, err := client.Tasks.GetTask(ctx, &getTaskRequest)
	if err != nil {
		return fmt.Errorf("error getting task: %w", err)
	}

	if task.Version == nil || task.Version.StatusVersion == nil {
		return fmt.Errorf("task version is missing")
	}

	taskStatusVersion := *task.Version.StatusVersion
	// Increment version and update to terminal state
	taskStatusVersion++

	// Create system principal with the agent entity ID
	principal := Lattice.Principal{
		System: &Lattice.System{
			EntityID: &entityId,
		},
	}

	taskStatus := Lattice.TaskStatus{
		Status: Lattice.TaskStatusStatusStatusDoneOk.Ptr(),
	}

	taskStatusUpdate := Lattice.TaskStatusUpdate{
		TaskID:        taskId,
		StatusVersion: &taskStatusVersion,
		NewStatus:     &taskStatus,
		Author:        &principal,
	}

	_, err = client.Tasks.UpdateTaskStatus(ctx, &taskStatusUpdate)
	if err != nil {
		return fmt.Errorf("error updating task status: %w", err)
	}

	return nil
}
```

agent 必须先使用 [`GetTask`](/reference/rest/tasks/get-task) 检索当前任务，获取当前 [`statusVersion`](/reference/rest/tasks/get-task#response.body.version.statusVersion)，然后在调用 [`UpdateTaskStatus`](/reference/rest/tasks/update-task-status) 前将其递增。
