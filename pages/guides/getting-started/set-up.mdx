# 安装

要使用 Lattice SDK 与 Lattice 集成，请先把凭证和环境端点设置为系统变量，然后按你选择的语言和协议安装 SDK。Lattice 将 gRPC 和 REST 都作为一等协议支持：

选择协议

有关如何为你的集成选择合适协议的更多信息，请参阅[选择协议](/guides/best-practices/choose-a-protocol)。

Go

[gRPC](https://schema-registry.developer.anduril.com/anduril/lattice-sdk/sdks/main:grpc/go) | [REST](https://github.com/anduril/lattice-sdk-go)

Java

[gRPC](https://schema-registry.developer.anduril.com/anduril/lattice-sdk/sdks/main:grpc/java) | [REST](https://github.com/anduril/lattice-sdk-java)

Python

[gRPC](https://schema-registry.developer.anduril.com/anduril/lattice-sdk/sdks/main:grpc/python) | [REST](https://github.com/anduril/lattice-sdk-python)

Rust

[gRPC](https://schema-registry.developer.anduril.com/anduril/lattice-sdk/sdks/main:rust)

TypeScript

[gRPC](https://schema-registry.developer.anduril.com/anduril/lattice-sdk/sdks/main:bufbuild/es) | [REST](https://github.com/anduril/lattice-sdk-javascript)

gRPC

如果你还无法访问 Lattice Schema Registry [schema-registry.developer.anduril.com](https://schema-registry.developer.anduril.com/)，SDK 和 schema 会公开镜像到 [buf.build/anduril/lattice-sdk](https://buf.build/anduril/lattice-sdk)。

Lattice SDK 文档中的 gRPC 示例使用 Go、Python 和 Rust。

如果你使用其他语言，可以从最多 16 种语言和多种插件中选择，以获取用于 gRPC 的 [Lattice SDK 构件](https://schema-registry.developer.anduril.com/anduril/lattice-sdk/sdks/main:grpc)。

## 开始之前

- 如果你使用 Lattice Sandboxes，请完成 Lattice Sandboxes 开发指南中的步骤，创建环境并生成凭证。

## 获取 gRPC SDK

Lattice 通过 [Lattice Schema Registry](https://schema-registry.developer.anduril.com/anduril/lattice-sdk/sdks) 提供多种语言和插件形式的 gRPC SDK。下列步骤展示如何在 Go、Python 和 Rust 中获取用于 gRPC 的 Lattice SDK：

Go

Python

Rust

1

安装[最新版本](https://go.dev/)的 Go。

2

创建新文件夹并初始化项目：

```
go mod init lattice-sdk-go-example
```

这会在项目目录中生成 `go.mod` 文件。

3

使用 [`grpc/go`](https://buf.build/anduril/lattice-sdk/sdks/main:grpc/go) 插件安装生成的 Lattice SDK gRPC stub：

```
go get schema-registry.developer.anduril.com/gen/go/anduril/lattice-sdk/grpc/go@v<latest-supported-version>
```

这会安装生成的 Lattice SDK gRPC stub 以及所需的 gRPC 运行时依赖，并在项目目录中创建 `go.sum` 文件。

4

导入 Lattice 并使用客户端：

```
package main

import (
    "buf.build/gen/go/anduril/lattice-sdk/grpc/go/anduril/entitymanager/v1/entitymanagerv1grpc"
)

func main() {
    client := entitymanagerv1grpc.NewEntityManagerAPIClient(conn)

    response, err := client.GetEntity(ctx, &entitymanagerv1.GetEntityRequest{
        EntityId: "<ENTITY_ID>",
    })
}
```

有关使用 Buf Schema Registry 的更多信息，请参阅 Buf [文档](https://buf.build/docs/bsr/generated-sdks/tutorial/)。

## 获取 REST SDK

Lattice 提供下列语言的 REST SDK：

Go

Java

Python

TypeScript

1

下载[最新版本](https://go.dev/learn/)的 Go。

2

验证安装：

```
go version
```

3

安装最新版本的 Lattice SDK：

```
go get github.com/anduril/lattice-sdk-go/v3
```

4

导入 Lattice 并使用客户端：

```
package main

import (
    "os"
    "fmt"
    "github.com/anduril/lattice-sdk-go/v3/client"
    "github.com/anduril/lattice-sdk-go/v3/option"
)

func main() {
    latticeEndpoint := os.Getenv("LATTICE_ENDPOINT")
    environmentToken := os.Getenv("ENVIRONMENT_TOKEN")

    client := client.NewClient(
        option.WithToken(environmentToken),
        option.WithBaseURL(fmt.Sprintf("https://%s", latticeEndpoint)),
    )

    client.Entities.GetEntity(
        context.TODO(),
        "ENTITY_ID",
    )
}
```
