# 快速入门

通过连接 Lattice 环境并发布一个水面舰艇实体来试用 Lattice SDK。

## 开始之前

- 完成设置步骤，登录 Sandbox 并创建环境。如果你无法访问 Lattice Sandbox，请申请加入 Lattice SDK developer program。
- 确认你已有 curl 命令行工具，或从 curl 网站安装它：```bash curl --version ```

## 发布航迹

要开始使用 Lattice，请考虑这个场景：一架可访问 Lattice 的友方无人机发现了一条新航迹，看起来像是一艘水面舰艇。要配置这架无人机将该航迹作为新实体发布到 Lattice，请执行以下操作：

1

### 获取认证令牌

使用你的 **Lattice Client ID** 和 **Lattice Client Secret** 从服务器获取访问令牌。该令牌的生命周期为 30 分钟。

```bash
export ENVIRONMENT_TOKEN=$(
    curl -s --request POST "https://$LATTICE_ENDPOINT/api/v1/oauth/token" \
    --header "Anduril-Sandbox-Authorization: Bearer $SANDBOXES_TOKEN" \
    --header "Content-Type: application/x-www-form-urlencoded" \
    --data-urlencode "grant_type=client_credentials" \
    --data-urlencode "client_id=$LATTICE_CLIENT_ID" \
    --data-urlencode "client_secret=$LATTICE_CLIENT_SECRET" | \
    jq -r .access_token )
```

2

### 定义实体

复制下面的实体 JSON 对象，并将其保存到名为 `entity.json` 的新文件中。将 `expiryTime` 的时间戳替换为未来时间，并将 `sourceUpdateTime` 替换为当前时间：

```json
{
    "entityId": "QUICKSTART_ENTITY_ID",
    "description": "Quickstart example",
    "isLive": true,
    "expiryTime": "<YYYY-MM-DDThh:mm:ssTZD>",
    "aliases": {
        "name": "Simulated Surface Vessel"
    },
    "milView": {
        "disposition": "DISPOSITION_FRIENDLY",
        "environment": "ENVIRONMENT_SURFACE"
    },
    "location": {
        "position": {
            "latitudeDegrees": 33.69447852698943,
            "longitudeDegrees": -117.9173785693163,
            "altitudeHaeMeters": 0
        }
    },
    "ontology": {
        "template": "TEMPLATE_TRACK",
        "platformType": "Surface_Vessel",
        "specificType": "N/A"
    },
    "provenance": {
        "integrationName": "command_line_integration",
        "dataType": "example_data_type",
        "sourceUpdateTime": "<YYYY-MM-DDThh:mm:ssTZD>"
    }
}
```

3

### 将实体发布到 Lattice

在保存 `entity.json` 的同一文件夹中，使用 curl 将实体发布到 Lattice：

```bash
curl --location \
--request PUT "https://$LATTICE_ENDPOINT/api/v1/entities" \
--header "content-type: application/json" \
--header "authorization: Bearer $ENVIRONMENT_TOKEN" \
--header "anduril-sandbox-authorization: Bearer $SANDBOXES_TOKEN" \
--include \
--data "@entity.json"
```

4

### 验证响应

如果请求成功，你会收到状态码为 `200` 且正文为空的响应：`{}`。

## 在 Lattice 中查找舰艇

要验证你的水面舰艇是否已成功发布到 Lattice，请执行以下操作：

1

打开 Lattice UI。

2

在 Entity Explorer 中查找该舰艇。按舰艇的 `aliases.name` 搜索以缩小列表范围：

![显示 Lattice Developer Console 中的 Entity Explorer。](/img/anduril.docs.buildwithfern.com/72c242c7f0277f5a308bd2efb784cfcd9675f4dab9d1790bd9b195c6df74c7d0/assets/images/screenshots/developer-console-entity-explorer.png)

3

打开该舰艇以查看详情页，并确认它的位置、名称和其他组件与你发布的实体一致：

![显示 Lattice Developer Console 中 Simulated Surface Vessel 的详情页。](/img/anduril.docs.buildwithfern.com/f4a1cc6ad39c631b2b40aba648adf11805f4168f9e5be4005d1ec8ffe8aa5a55/assets/images/screenshots/developer-console-surface-vessel-detail.png)
