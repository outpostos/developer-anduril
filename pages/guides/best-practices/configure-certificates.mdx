# 连接离线环境

默认情况下，Lattice SDK 会根据操作系统的受信任 Certificate Authority (CA) 存储验证 TLS 证书。

当 Lattice 环境离线或物理隔离时，它部署在无法访问公共 CA 基础设施的本地网络中。该环境会提供由私有 Anduril CA 签名的证书，而该 CA 不在系统信任存储中，因此 SDK 客户端无法验证证书，连接会失败。

本指南介绍两种连接方式：

1. 使用 Anduril 签发的证书：这种方法让 SDK 信任你的环境，同时保持完整 TLS 验证启用。这是生产环境中的推荐方法。
2. 对自签名证书跳过 TLS 验证：当 Anduril 代表无法签发证书时，此方法可让你连接。仅在开发环境中使用此方法。

## 开始之前

- 完成设置中的步骤，配置环境变量：LATTICE_ENDPOINT、LATTICE_CLIENT_ID 和 LATTICE_CLIENT_SECRET。

gRPC 认证

如果你将 gRPC 与客户端凭证一起使用，请在运行本页示例前[设置令牌刷新模块](/guides/getting-started/authenticate#using-grpc)。

## 使用 Anduril 签发的证书

这是推荐方法，因为它会保持完整 TLS 验证启用。你从 Anduril 获取 CA 证书，将其添加到信任存储，并配置 SDK 将其信任为根 CA。SDK 仍会验证证书链、主机名和过期日期。

要获取证书、将其添加到信任存储并配置 SDK 信任它，请执行以下步骤：

1

### 获取 Anduril 签发的证书

联系 Anduril 代表，获取适用于你的 Lattice 环境的 CA 证书。证书会以 PEM 编码文件形式交付。由于交付机制各不相同，请按照 Anduril 代表提供的说明获取证书。

2

### 将证书添加到系统信任存储

将证书添加到操作系统信任存储，使机器上的客户端信任它：

```
sudo security add-trusted-cert -d -r trustRoot \
  -k /Library/Keychains/System.keychain /path/to/anduril-ca.pem
```

3

### 设置包含证书路径的环境变量

设置指向证书文件的 `LATTICE_CA_CERT_PATH` 环境变量。后续步骤中的示例会从 `LATTICE_CA_CERT_PATH` 加载 CA 证书，并配置 Lattice 客户端将其信任为根 CA：

```bash
export LATTICE_CA_CERT_PATH=/path/to/anduril-ca.pem
```

4

### 初始化客户端

导入环境变量并初始化客户端。`LATTICE_CA_CERT_PATH` 是你从 Anduril 代表处收到的 PEM 证书文件路径。也可以使用本地 `.env` 文件实现相同效果：

```
package main

import (
	"context"
	"crypto/tls"
	"crypto/x509"
	"fmt"
	"net/http"
	"os"

	Lattice "github.com/anduril/lattice-sdk-go/v4"
	"github.com/anduril/lattice-sdk-go/v4/client"
	"github.com/anduril/lattice-sdk-go/v4/option"
)

func main() {
	latticeEndpoint := os.Getenv("LATTICE_ENDPOINT")
	clientID := os.Getenv("LATTICE_CLIENT_ID")
	clientSecret := os.Getenv("LATTICE_CLIENT_SECRET")
	sandboxesToken := os.Getenv("SANDBOXES_TOKEN")

	// Path to the Anduril-issued CA certificate in PEM format
	caCertPath := os.Getenv("LATTICE_CA_CERT_PATH")

	// Initialize the client
	LatticeClient, err := createLatticeClient(latticeEndpoint, clientID, clientSecret,
		sandboxesToken,
		caCertPath,
	)
	if err != nil {
		fmt.Printf("Error creating Lattice client: %v\n", err)
		os.Exit(1)
	}

	// Use the client
	ctx := context.Background()
	entity, err := LatticeClient.Entities.GetEntity(
		ctx,
		&Lattice.GetEntityRequest{
			EntityID: "Demo-Sim-Asset1",
		},
	)

	if err != nil {
		fmt.Printf("Error fetching entity: %v\n", err)
	} else {
		fmt.Printf("Asset name     | %s\n", *entity.GetAliases().GetName())
		fmt.Printf("Asset location | %f, %f\n", *entity.GetLocation().GetPosition().GetLatitudeDegrees(),
			*entity.GetLocation().GetPosition().GetLongitudeDegrees())
	}
}

func createLatticeClient(endpoint string, clientID string, clientSecret string,
	sandboxesToken string,
	caCertPath string,
) (*client.Client, error) {

	headers := http.Header{}
	if sandboxesToken != "" {
		headers.Add("Anduril-Sandbox-Authorization", fmt.Sprintf("Bearer %s", sandboxesToken))
	}

	// Load the Anduril-issued CA certificate and add it to the trust pool
	certPool, err := x509.SystemCertPool()
	if err != nil {
		certPool = x509.NewCertPool()
	}
	if caCertPath != "" {
		pemBytes, err := os.ReadFile(caCertPath)
		if err != nil {
			return nil, fmt.Errorf("reading CA certificate: %w", err)
		}
		if !certPool.AppendCertsFromPEM(pemBytes) {
			return nil, fmt.Errorf("failed to append CA certificate from %s", caCertPath)
		}
	}

	httpClient := &http.Client{
		Transport: &http.Transport{
			TLSClientConfig: &tls.Config{
				RootCAs: certPool,
			},
		},
	}

	latticeClient := client.NewClient(
		option.WithClientCredentials(clientID, clientSecret),
		option.WithBaseURL(fmt.Sprintf("https://%s", endpoint)),
		option.WithHTTPHeader(headers),
		option.WithHTTPClient(httpClient),
	)

	return latticeClient, nil
}
```

## 对自签名证书跳过 TLS 验证

如果无法为开发环境获取 Anduril 签发的证书，可以配置 SDK 跳过 TLS 验证。这样 SDK 会在不验证服务器证书的情况下连接。

跳过 TLS 验证会禁用证书验证，使连接暴露于拦截和篡改风险。仅在 Anduril 代表无法签发 Anduril 证书的开发环境中使用此方法。生产环境请改用 [Anduril 签发的证书](#use-an-anduril-issued-certificate)。

要跳过 TLS 验证并配置客户端，请执行以下步骤：

1

### 设置环境变量

设置 `SKIP_TLS_VERIFY` 环境变量，让客户端知道应跳过证书验证。后续步骤中的示例会读取 `SKIP_TLS_VERIFY`，并配置跳过 TLS 验证的自定义 Lattice 客户端：

```bash
export SKIP_TLS_VERIFY=true
```

2

### 初始化客户端

导入环境变量并初始化客户端。`SKIP_TLS_VERIFY` 控制客户端是否验证服务器证书。也可以使用本地 `.env` 文件实现相同效果：

```
package main

import (
	"context"
	"crypto/tls"
	"fmt"
	"net/http"
	"os"

	Lattice "github.com/anduril/lattice-sdk-go/v4"
	"github.com/anduril/lattice-sdk-go/v4/client"
	"github.com/anduril/lattice-sdk-go/v4/option"
)

func main() {
	latticeEndpoint := os.Getenv("LATTICE_ENDPOINT")
	clientID := os.Getenv("LATTICE_CLIENT_ID")
	clientSecret := os.Getenv("LATTICE_CLIENT_SECRET")
	sandboxesToken := os.Getenv("SANDBOXES_TOKEN")

	// Load the SKIP_TLS_VERIFY variable
	skipTLSVerify := os.Getenv("SKIP_TLS_VERIFY") == "true"

	// Initialize the client
	LatticeClient, err := createLatticeClient(latticeEndpoint, clientID, clientSecret,
		sandboxesToken,
		skipTLSVerify,
	)
	if err != nil {
		fmt.Printf("Error creating Lattice client: %v\n", err)
		os.Exit(1)
	}

	// Use the client
	ctx := context.Background()
	entity, err := LatticeClient.Entities.GetEntity(
		ctx,
		&Lattice.GetEntityRequest{
			EntityID: "Demo-Sim-Asset1",
		},
	)

	if err != nil {
		fmt.Printf("Error fetching entity: %v\n", err)
	} else {
		fmt.Printf("Asset name     | %s\n", *entity.GetAliases().GetName())
		fmt.Printf("Asset location | %f, %f\n", *entity.GetLocation().GetPosition().GetLatitudeDegrees(),
			*entity.GetLocation().GetPosition().GetLongitudeDegrees())
	}
}

func createLatticeClient(endpoint string, clientID string, clientSecret string,
	sandboxesToken string,
	skipTLSVerify bool,
) (*client.Client, error) {

	headers := http.Header{}
	if sandboxesToken != "" {
		headers.Add("Anduril-Sandbox-Authorization", fmt.Sprintf("Bearer %s", sandboxesToken))
	}

	// Configure the InsecureSkipVerify option
	httpClient := &http.Client{
		Transport: &http.Transport{
			TLSClientConfig: &tls.Config{
				InsecureSkipVerify: skipTLSVerify,
			},

	}

		option.WithClientCredentials(clientID, clientSecret),
```
