# 对象概览

在 Lattice 中，**对象**是表示单个文件或一段数据的数据模型。Objects API 围绕 Anduril 的弹性内容分发网络 (CDN) 实现，会在 [Lattice mesh](https://www.anduril.com/lattice/lattice-mesh) 中分发对象。

将 Objects API 与 Entities 配合使用，可以实现航迹缩略图、舰艇清单等用例。

限制

对象大小必须小于 1 GiB。

## 数据分发

每个 Lattice 环境都会运行一个 CDN 实例。在 Lattice mesh 部署中，网格中的每个节点都会运行一个 CDN 实例。这让 Lattice 可以使用分层查找机制检索对象：

![显示 Lattice 使用的内容分发网络的架构图。](/img/anduril.docs.buildwithfern.com/be83e074bce1b6d6be87c091b656fb4863e4a312bf172ffdefe9ff12e9cf4eef/assets/images/diagrams/objects-cdn.png)

如果请求的数据未在本地缓存，Lattice 会查询网格中同一层的对等节点。如果某个对等节点拥有数据，系统会发出请求，先将 blob 流式传输并缓存在本地，再发送给客户端。如果同一层没有对等节点拥有所请求的数据，系统会按照特定优先级顺序查询下一更高层的节点。

## 对象 schema

Objects API 实现 `PathMetadata` 和 `ContentIdentifier` schema，用于在 Lattice 环境中存储和检索对象：

**`PathMetadata`**:

- `content_identifier` _ContentIdentifierRequired_
  唯一标识环境中对象路径的字符串。

- `size_bytes` _IntegerRequired_
  对象大小，单位为字节。

- `last_updated_at` _DatetimeRequired_
  对象最后更新时间。

- `expiry_time` _datetime_
  对象过期并从环境中删除的未来时间。

**`ContentIdentifier`**:

- `path` _StringRequired_
  环境中的唯一对象路径。

- `checksum` _String_
  对象的 SHA-256 校验和，用于验证 Lattice 中数据的完整性。

## 对象生命周期

Lattice 中的对象具有下列生命周期状态：

1

### 创建

上传对象时，Object Store 会更新对象的 [`last_updated_at`](/reference/rest/objects/upload-object#response.body.last_updated_at)。

2

### 过期

对象过期时，Object Store 会自动将其从 Lattice 删除。上传对象时，可以通过设置可选的 `Time-to-Live` header 来定义 [`expiry_time`](/reference/rest/objects/upload-object#response.body.expiry_time%5D)。如果你将对象与 Lattice 中的实体关联，应用必须相应地处理实体 [`media`](/reference/rest/entities/publish-entity#request.body.media) 组件的重置。

3

### 删除

可以使用 [`DeleteObject`](/reference/rest/objects/delete-object) API 在对象过期前将其从 Lattice 删除。与对象过期类似，如果对象与 Lattice 中的实体关联，你必须处理实体 `media` 组件的重置。
