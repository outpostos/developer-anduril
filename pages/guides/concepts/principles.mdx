# 原则

Lattice SDK™ 体现的核心开发原则

自成立以来，Anduril 一直擅长构建能够在艰苦、敌对环境中可靠运行的集成系统。Anduril 最早的 Sentry 塔台会在边缘本地执行计算机视觉、传感器融合等关键工作负载，自动从环境中分诊疑似威胁，且不依赖人工操作员。

随着新产品推出，我们继续把处理与协作推向边缘，而不是把逻辑集中到数据中心服务器上。我们体现的是一种本地优先的方法，这构成了 Anduril 差异化能力的主干。

我们把这条主干称为 **Lattice**。

## 开发原则

**Lattice SDK™** 通过下列核心原则，加速你开发去中心化应用的能力；这些应用能够与网格中的其他系统互操作：

- **本地优先** - 为了交付能在降级网络环境中良好运行的应用，开发时要考虑带宽利用率，并假设代码运行时所在网络可能间歇性不可用。
- **开放数据交换** - 为了让你的系统与 Lattice 有效协作，它们必须使用同一种语言。为此，Lattice 在 Anduril 的所有产品和应用中使用标准化数据模型。学习 Lattice 数据模型，并利用它们构建更有韧性的数据服务和集成。

这种方法在不需要大量预先协调的情况下促进互操作性。

## 数据模型

借助 SDK 及其开放数据模型，Lattice 让你可以把高度可定制的数据系统和硬件平台，与它不断增长且经过实地检验的稳健集成体系连接起来。

Lattice SDK 实现了下列基础结构化数据模型：

实体

实体用于建模现实世界中对操作员有意义的任何事物。

任务

任务分配让你能够向连接到 Lattice 的 agent 发送顺序命令。

对象

对象让你能够在 Lattice 中存储分布式二进制数据。
