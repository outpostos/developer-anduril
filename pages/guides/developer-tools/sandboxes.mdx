# Lattice Sandboxes

Lattice Sandboxes 是一个安全、隔离的平台，可用于创建带有模拟数据的环境，以开发和测试你的 Lattice SDK 应用。在 Sandboxes 上开发的应用具备可移植性，可根据你的环境需求用于其他 Lattice 部署。

价格

Lattice Sandboxes 环境免费提供。你可以对环境发起不限次数的免费 API 调用，以在 Lattice 中创建、流式传输实体并为实体分配任务。

## 开始之前

- 如果你无法访问 Lattice Sandboxes，请申请加入 Lattice SDK developer program。

## 登录

Anduril 使用 Okta 对 Lattice Sandboxes 访问进行认证。多因素认证 (MFA) 通过 passkey 完成，例如浏览器 passkey、操作系统生物识别，或实体 FIDO/UBI 安全密钥。

浏览器支持

请使用 Chrome 或基于 Chromium 的浏览器（例如 Microsoft Edge 或 Brave）访问 Lattice Sandboxes 开发者门户。Firefox 不受支持，会导致你无法完成登录流程。

如果这是你首次登录，请激活 Okta 账号并注册 passkey：

1

打开欢迎邮件并选择

Activate Okta Account

链接。该链接会在邮件发出七天后过期。

2

在

Set up security methods

页面中，在

Password

旁边选择

Set up

，然后选择并确认密码。

3

在 **Security Key or Biometric Authenticator** 旁边选择 **Set up**，然后注册下列 passkey 选项之一：

- 浏览器 passkey - 存储在浏览器密码管理器中，因此你可以从已登录同一浏览器个人资料的任何设备登录。
- 操作系统生物识别 - 使用 Touch ID、Face ID、Windows Hello，或绑定到当前设备的其他内置平台认证器。
- 实体 FIDO 或 UBI 密钥 - 使用 YubiKey 等硬件令牌，可随身携带并在设备之间使用。

激活后要登录，请执行以下操作：

1

打开

Lattice Sandboxes sign-in page

。

2

对于

Username

，输入你用于申请访问 Lattice Developer program 的电子邮件地址。

3

对于

Password

，输入你在激活期间创建的密码。

4

使用你注册的认证器方式完成 passkey 挑战。成功后，Okta 会将你重定向到 Lattice Sandboxes 仪表盘。

要管理 passkey 和密码，请访问 `https://login.developer.anduril.com/account-settings/home`。如果无法访问 passkey，请联系 `lattice-developers@anduril.com` 获取帮助。

登录后，仪表盘会显示与你账号关联的所有现有环境及每个环境的状态。

## 创建环境

要创建新环境，请打开 [Environment Catalog](https://sandboxes.developer.anduril.com/environment-catalog)，然后执行以下操作：

1

选择 **New Environment**。

![显示空环境列表](/img/anduril.docs.buildwithfern.com/50acdfa5596cba9813763367a61c168ee58a82776b25d4ac1fafda0053e9d5ac/assets/images/screenshots/environments-list-null.png)

2

在 **Environment Catalog** 页面，选择 **Lattice** 并点击 **Create**。你会被重定向到环境创建详情页，并在那里看到环境状态：

![显示环境详情页](/img/anduril.docs.buildwithfern.com/50b68edbbda8e34fb5b1e6c4fd0db6e979e833aaacd497b965af21c3b7a7a11f/assets/images/screenshots/environment-details.png)

3

状态变为 **Ready** 后，查看下列详情：

- `Resource Endpoint`
  用它启动 Lattice UI，或以编程方式连接到 Lattice。

- `Lattice Client ID`
  使用 client ID 通过 Lattice SDK 授权你的集成。

- `Lattice Client Secret`
  使用 client secret 通过 Lattice SDK 认证你的集成。

- `Lattice User`
  用于登录 Lattice UI 的用户名。

- `Lattice Password`
  用于登录 Lattice UI 的密码。

- `Lattice Auth Token`
  这是你的**环境令牌**。除 [Sandboxes 令牌](#set-up-credentials)外，也请保存该令牌，以便向 Lattice API 认证请求。

4

点击 Lattice URL 链接确认你可以访问环境，然后使用提供的用户名和密码登录。

限制

- 在 Sandboxes 中最多可同时创建 2 个环境。
- 环境最长生命周期为 12 小时。
- 环境最长空闲生命周期为 2 小时。你必须发起网络调用，或登录 Lattice UI，才能保持环境活跃。
- 使用客户端凭证获取的访问令牌生命周期为 30 分钟。

## 设置凭证

要查询 Sandboxes 环境，你需要：

- Sandboxes 令牌（anduril-sandbox-authorization header）- 这是账号级授权令牌。只需创建一次，然后即可用它访问你的所有环境。
- Lattice Client ID - 这是你的集成用于向环境授权的凭证。创建新环境时会自动生成 Client ID。
- Lattice Client Secret - 这是你的集成用于向环境认证的凭证。创建新环境时会自动生成 Client Secret。

运行时需要所有凭证才能与 Lattice Sandboxes 交互。**Sandboxes Proxy** 会验证你的 Sandboxes 令牌，然后将请求转发到你的环境。

![显示 Lattice Sandboxes 授权流程的图示。](/img/anduril.docs.buildwithfern.com/aff262eaf9f72a8e3e87f59fd6d5db7d5e948bd30bc3e0483a98e22f6d6c61fa/assets/images/diagrams/authorization-flow.png)

要创建新的 Sandboxes 令牌，请执行以下操作：

1

打开 Sandboxes 门户中的

Account & Security

页面，而不是 Lattice 环境中的页面。该令牌在生命周期内可用于所有环境。

2

在 **Bearer tokens** 部分，点击 **+ New Token**：

![显示可创建和管理授权令牌的 Account & Security 页面。](/img/anduril.docs.buildwithfern.com/f9fc9ebcfe81ab1f18459a58d0e220ae9f3af95240b817d8b02166f1a897a27e/assets/images/screenshots/bearer-token.png)

3

在 **Create Bearer Token** 模态框中输入以下内容：

- Bearer token name - 为 Sandboxes 令牌输入一个描述性名称。
- Bearer token expiration - 选择过期时间范围。

4

点击 **Create** 生成 Sandboxes 令牌，然后保存该令牌。

完成此步骤后，Sandboxes 令牌将不会再次显示。

要对发往 Sandboxes 环境的 API 请求进行认证，你需要使用 **Lattice Client ID** 和 **Lattice Client Secret** 获取访问令牌。

如果环境页面的 “Resource Credentials” 下未显示 **Lattice Client ID** 或 **Lattice Client Secret**，请联系 Anduril 代表。

1

向 `/api/v1/oauth/token` 端点发送包含 `client_id` 和 `client_secret` 的 `POST` 请求。

```bash
curl --request POST "https://$LATTICE_ENDPOINT/api/v1/oauth/token" \
        --header "Anduril-Sandbox-Authorization: Bearer $SANDBOXES_TOKEN" \
        --header "Content-Type: application/x-www-form-urlencoded" \
        --data-urlencode "grant_type=client_credentials" \
        --data-urlencode "client_id=$LATTICE_CLIENT_ID" \
        --data-urlencode "client_secret=$LATTICE_CLIENT_SECRET"
```

2

如果请求成功，你会收到状态码为 `200` 的响应。正文会包含以下数据：

```json
{
    "access_token" : "*****",
    "expires_in" : 1800,        // seconds
    "scope": "lattice"
}
```

将 `access_token` 导出为环境变量。

```bash
export ENVIRONMENT_TOKEN="*****"
```

3

现在可以使用 `access_token` 作为 Authorization 令牌与 Lattice 交互。

```bash
curl -X GET https://$LATTICE_ENDPOINT/api/v1/objects \
     -H "Authorization: Bearer $ENVIRONMENT_TOKEN" \
     -H "Anduril-Sandbox-Authorization: Bearer $SANDBOXES_TOKEN"
```

令牌刷新

返回的 `access_token` 仅在 `expires_in` 指定的秒数内有效。如果你通过 REST 客户端访问 SDK，客户端会自动为你管理刷新。如果你使用 gRPC 或 cURL 与 SDK 交互，则必须根据 `expires_in` 属性自行管理令牌刷新。
