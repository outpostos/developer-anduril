# 示例应用

## 实体可视化器

实体用于刻画车辆、舰船、航空器等真实世界对象。Lattice 数据模型提供一组开放且灵活的属性，这些属性可以由自动化传感器系统、战术数据链以及人工操作员输入来定义。此示例应用渲染一个简单 Web 应用，在地图上展示环境中的所有实体。

此应用旨在作为学习实体以及实体开放数据模型所支持各类属性的起点：

## 向资产下发任务

任务是核心开放数据模型，用于向有人或无人 agent 传达执行目标活动的请求，例如移动到指定位置、将传感器指向感兴趣位置，或对其他实体执行更主动的动作。

此仓库演示如何定义并操作自定义 `Orbit` 任务。该任务在 `.proto` 文件中定义，并发布到 Lattice Schema Registry。

三个独立程序演示：

- 向 Lattice 发布表示传感器兴趣点的航迹
- 创建可接受并执行 Orbit 任务的可任务化资产
- 使用通用作战图 (COP) 根据环境中的实体识别资产，并自动向资产下发任务。

这些程序协同演示一个自动化任务分配场景。

## Objects CLI

在 Lattice 中，[Objects API](/reference/rest/objects/list-objects) 提供内容分发网络服务，用于在边缘实现弹性数据存储。此示例应用实现了一个命令行界面，让开发者可以与 Objects API 交互，在整个 Lattice 环境中管理文件。

Objects CLI 提供一组完整操作，包括使用可自定义存活时间上传文件、将对象下载到指定位置、获取元数据、按前缀过滤列出对象，以及从存储中删除对象。

## 集成海事 AIS 位置数据

AIS（自动识别系统）船舶交通数据集是船舶识别与定位数据仓库。这些数据由美国海岸警卫队通过船载导航安全设备采集，该设备会实时传输并监控美国及国际水域中船舶的位置与特征。

此示例集成使用预先提取的 AIS 数据表示水面船舶随时间变化的位置，然后将该船舶建模为带有周期性位置更新的实体。实体发布到 Lattice 后，可由其他应用可视化或引用。

## 实体缩略图

在 Lattice 中，对象是一种数据模型，可让你在整个环境中存储和访问文件。[**Objects**](/reference/rest/objects/list-objects) API 是一种内容分发网络服务，在边缘提供弹性数据存储。将对象与实体结合使用，可以实现航迹缩略图、船舶清单等用例。
