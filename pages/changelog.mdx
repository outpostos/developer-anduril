2026 年 4 月 22 日

### [StreamTasks gRPC 支持](/changelog/2026/4/22)

Lattice SDK 现在支持使用 gRPC API 实时流式传输任务更新：

- 新增 StreamTasks gRPC 端点，用于建立持久连接以流式传输任务事件
- 实现 Go/gRPC 示例，演示如何连接并处理任务流
- 更新文档，在现有 REST 示例旁加入 gRPC 使用模式

### [主要功能](/changelog/2026/4/22#2026-04-22-key-features)

`StreamTasks` gRPC API 提供与 REST 版本相同的可配置参数：

- heartbeatIntervalMs：配置服务器发送 heartbeat 事件以验证连接健康的频率。
- excludePreexistingTasks：控制是只流式传输连接建立后创建的新任务，还是也包含既有任务。
- taskType：允许按任务类型前缀过滤流，减少带宽使用并聚焦相关任务更新。

### [文档更新](/changelog/2026/4/22#2026-04-22-documentation-updates)

作为此版本的一部分，[Operate on tasks](/guides/tasks/command-and-operate) 指南已更新 Go/gRPC 代码示例。该示例演示如何建立任务流连接、处理 heartbeat 事件，并使用 gRPC 协议处理传入任务事件。

2026 年 4 月 14 日

### [取消任务 API](/changelog/2026/4/14)

Lattice SDK 现在支持通过 REST 和 gRPC 中均可用的 [`CancelTask`](/reference/rest/tasks/cancel-task) API 取消任务。该 API 允许操作员请求取消任务，使你能更好地控制任务生命周期管理。

取消行为取决于任务当前状态：

- 尚未发送给 agent 的任务会立即取消并转换为终止状态。
- 已发送给 agent 的任务会收到取消请求，agent 可根据任务执行状态接受或拒绝。

2026 年 1 月 15 日

### [Sandboxes 的 OAuth 2.0 client credentials](/changelog/2026/1/15)

Lattice 现在支持使用 OAuth 2.0 client credentials flow 进行机器到机器 (M2M) 认证。短期令牌让你可以更好地控制权限并提升安全性。

现有用户

在推出此新功能期间，我们会继续支持现有 Lattice 部署中的长期令牌。

如果你已有部署到生产 Lattice 环境的集成，建议与 Anduril 代表协作，确定迁移到 OAuth 2.0 client credentials flow 的时间表。

如果你正在 Lattice Sandboxes 中构建新集成，建议开始使用 OAuth 2.0 client credentials flow。

[Lattice SDK for Java 2.3.0](https://github.com/anduril/lattice-sdk-java/releases/tag/v2.3.0) 引入了向 API 请求添加认证标头的简化方式：

- 在 Lattice client builder 中新增 addHeader 方法，无需再创建自定义 OkHttpClient 实例。

- 移除了此前必需的 OkHttpClient interceptor 样板配置。

2025 年 8 月 11 日

### [新功能](/changelog/2025/8/11)

新的 `StreamEntities` API 提供多个可配置参数：

- preExistingOnly：控制是仅流式传输既有实体，还是包含实时更新。
- heartbeatIntervalMS：配置服务器发送 heartbeat 事件的频率。
- componentsToInclude：允许过滤要流式传输的实体组件，从而减少带宽使用并提升性能。

### [文档更新](/changelog/2025/8/11#2025-08-11-documentation-updates)

作为此版本的一部分，[Watch entities](/guides/entities/watch) 指南已更新所有受支持语言的代码示例。每个示例都演示基础实体流式传输和特定组件过滤，为将实时实体数据集成到 Lattice 应用提供常见模式。
