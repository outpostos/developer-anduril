## Java SDK 改进

[Lattice SDK for Java 2.3.0](https://github.com/anduril/lattice-sdk-java/releases/tag/v2.3.0) 引入了向 API 请求添加认证标头的简化方式：

- 在 Lattice client builder 中新增 addHeader 方法，无需再创建自定义 OkHttpClient 实例。
- 更新所有 Java 示例以使用这种新方式，使代码更简洁、更易维护。
- 移除了此前必需的 OkHttpClient interceptor 样板配置。
