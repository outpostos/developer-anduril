# 更新日志

2025 年 10 月 3 日

## Java SDK v3

[Lattice SDK for Java v3](https://github.com/anduril/lattice-sdk-java/releases/tag/v3.0.0) 引入多项变更：

- ⚠️ 破坏性变更 - 更改 enum 类型的生成方式以支持前向兼容 enum。它们现在遵循 visitor pattern
- SSE streaming 修复

```
switch (event.getEventType().get()) {
    case EVENT_TYPE_PREEXISTING:
        System.out.println("Received pre-existing entity event");
        break;
    default:
        System.out.println("Default case");
        break;
}
```
