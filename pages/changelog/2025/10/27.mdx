# 更新日志

2025 年 10 月 27 日

## 新版 SDK

今天，我们发布了四种语言的新版 major Lattice SDK：

- Lattice SDK for Go
- Lattice SDK for Java
- Lattice SDK for Javascript
- Lattice SDK for Python

这修复了 `Entity` 上 [`status`](/reference/rest/entities/publish-entity#response.body.status) 组件此前建模不正确的问题。如果你使用了此组件，需要更新代码以引用消息上的新字段。
