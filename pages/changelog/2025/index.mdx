# 更新日志

2025 年 7 月 24 日

现有开发者

此次 major 版本更新引入了相对于 SDK v1 的破坏性变更。如果你是当前 Lattice SDK 开发者，v1 版本会继续工作，但不再维护。建议升级到 Lattice SDK v2。

Lattice SDK v1 原生支持 gRPC，而 v2 使用 OpenAPI 以提供更简化的体验。要选择适合你的迁移路径，请参阅[迁移指南](/reference/overview/versioning/migrating-to-v2)。

## 新版 REST SDK

Lattice SDK 通过 REST 支持改进了 SDK 访问方式。只需用你选择的语言[安装 Lattice SDK](/guides/getting-started/set-up#get-the-sdk)，即可开始使用 Lattice 构建：

```
package main

import (
    "os"
    "fmt"
    "github.com/anduril/lattice-sdk-go/v2/client"
    "github.com/anduril/lattice-sdk-go/v2/option"
)

func main() {
    latticeEndpoint := os.Getenv("LATTICE_ENDPOINT")
    environmentToken := os.Getenv("ENVIRONMENT_TOKEN")

    client := client.NewClient(
	    option.WithToken(environmentToken),
	    option.WithBaseURL(fmt.Sprintf("https://%s", latticeEndpoint)),
    )

    client.Entities.GetEntity(
	    context.TODO(),
	    "ENTITY_ID",
    )
}
```

## Buf Schema registry

Lattice Protobuf 定义现已发布，并可从 [Buf Schema registry](https://buf.build/anduril/lattice-sdk/) 获取。

![Shows the Buf schema registry.](/img/anduril.docs.buildwithfern.com/7cf7ebc2f433fec5e77a2b7061b720f89bc2932716d34c05a73360a24cef1943/assets/images/screenshots/lattice-buf-schema-registry.png)

使用 Lattice protos 和你选择的插件，为所选语言生成 SDK 产物。更多信息以及 Go 示例请参阅 [Generate the Lattice SDK for gRPC](/guides/getting-started/set-up#generate-the-sdk-for-grpc)。

## Objects API

Lattice 现在支持弹性的分布式二进制对象存储，让你能高效存储二进制数据，并将其与环境中的实体关联。用例包括：

- 在 Lattice UI 中为航迹创建图片缩略图。
- 维护实体的 CSV 数据，用于实现船舶清单或其他相关实体元数据。

![Lattice UI object store.](/img/anduril.docs.buildwithfern.com/dc72382af2efe25a3f117a76ec39a7aaf531e7d501fadb6d805e24cdab27578b/assets/images/screenshots/changelog-vessel-track.png)

[Objects API](/reference/rest/objects/list-objects) 可让你在 Lattice mesh 中上传、获取和删除对象。更多信息请参阅 *Lattice SDK 指南* 中的 [Objects](/guides/objects/overview)。
