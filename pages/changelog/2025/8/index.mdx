# 更新日志

2025 年 8 月 11 日

Lattice SDK 现在支持在所有受支持语言中使用 REST API 实时流式传输实体更新：

- 新增 StreamEntities API，用于建立持久连接以流式传输实体事件
- 实现 Go、Java、Python 和 TypeScript 的实体流式传输示例
- 更新文档以同时演示基础流式传输和组件过滤

## 新功能

新的 `StreamEntities` API 提供多个可配置参数：

- preExistingOnly：控制是仅流式传输既有实体，还是包含实时更新。
- heartbeatIntervalMS：配置服务器发送 heartbeat 事件的频率。
- componentsToInclude：允许过滤要流式传输的实体组件，从而减少带宽使用并提升性能。

## 文档更新

作为此版本的一部分，[Watch entities](/guides/entities/watch) 指南已更新所有受支持语言的代码示例。每个示例都演示基础实体流式传输和特定组件过滤，为将实时实体数据集成到 Lattice 应用提供常见模式。
