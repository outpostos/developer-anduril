# 更新日志

2026 年 2 月 5 日

## 任务分配的 server-sent events (SSE)

Lattice SDK 现在支持两个使用 server-sent events (SSE) 在 Lattice 中实时监控任务的新 API：

1. StreamTasks - 用于监控整个 Lattice 环境中的所有任务。
2. StreamAsAgent - 用于接收分配给特定 agent 的任务。

这些新功能无需轮询即可即时更新任务创建、状态变更和完成情况，并替代此前基于轮询的方式：

- 过滤选项：使用类型前缀过滤聚焦特定任务。
- Heartbeat 机制：通过可配置的 heartbeat 间隔验证连接健康。
- 完整事件数据：访问完整任务详情，包括状态、描述和元数据。
- 高效资源使用：相比轮询减少网络流量和服务器负载。

### StreamTasks

`StreamTasks` API 支持集中监控 Lattice 环境中的所有任务，不受分配 agent 限制。

```
// Create task stream request
request := &Lattice.TaskStreamRequest{
    HeartbeatIntervalMs:     Lattice.Int(10000),
    ExcludePreexistingTasks: Lattice.Bool(false),
    TaskType: &Lattice.TaskStreamRequestTaskType{
        TaskStreamRequestTaskTypeTaskTypePrefix: &Lattice.TaskStreamRequestTaskTypeTaskTypePrefix{
            TaskTypePrefix: "type.googleapis.com/<your-organization>.tasks",
        },
    },
}

// Start the task stream
stream, err := LatticeClient.Tasks.StreamTasks(ctx, request)
```

### StreamAsAgent

`StreamAsAgent` API 替代此前的 ListenAsAgent 方法，允许 agent 使用 server-sent events 监听专门分配给自己的任务。

```
// Create agent stream request
agentRequest := &Lattice.AgentStreamRequest{
    AgentSelector: &Lattice.EntityIdsSelector{
        EntityIds: []string{entityId},
    },
}

// Start streaming tasks for the agent
agentStream, err := LatticeClient.Tasks.StreamAsAgent(ctx, agentRequest)
```

有关监控任务的更多信息，请参阅 Lattice SDK 指南中的 [Command and operate](/guides/tasks/command-and-operate)。
