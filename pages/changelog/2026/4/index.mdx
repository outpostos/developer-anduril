## 取消任务s API

Lattice SDK 现在支持通过 REST 和 gRPC 中均可用的 [`CancelTask`](/reference/rest/tasks/cancel-task) API 取消任务。该 API 允许操作员请求取消任务，使你能更好地控制任务生命周期管理。

取消行为取决于任务当前状态：

- 尚未发送给 agent 的任务会立即取消并转换为终止状态。
- 已发送给 agent 的任务会收到取消请求，agent 可根据任务执行状态接受或拒绝。

有关在集成中使用 `CancelTask` API 的更多信息，请参阅 Lattice SDK 指南中的 [Cancel tasks](/guides/tasks/command-and-operate#cancel-tasks)。

API 参考详情请参阅 [`CancelTask` (REST)](/reference/rest/tasks/cancel-task) 和 [`CancelTask` (gRPC)](/reference/grpc/taskmanager-v1/cancel-task)。
