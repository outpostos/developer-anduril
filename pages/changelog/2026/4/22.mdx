# 更新日志

2026 年 4 月 22 日

## StreamTasks gRPC 支持

Lattice SDK 现在支持使用 gRPC API 实时流式传输任务更新：

- 新增 StreamTasks gRPC 端点，用于建立持久连接以流式传输任务事件
- 实现 Go/gRPC 示例，演示如何连接并处理任务流
- 更新文档，在现有 REST 示例旁加入 gRPC 使用模式

## 主要功能

`StreamTasks` gRPC API 提供与 REST 版本相同的可配置参数：

- heartbeatIntervalMs：配置服务器发送 heartbeat 事件以验证连接健康的频率。
- excludePreexistingTasks：控制是只流式传输连接建立后创建的新任务，还是也包含既有任务。
- taskType：允许按任务类型前缀过滤流，减少带宽使用并聚焦相关任务更新。

## 文档更新

作为此版本的一部分，[Operate on tasks](/guides/tasks/command-and-operate) 指南已更新 Go/gRPC 代码示例。该示例演示如何建立任务流连接、处理 heartbeat 事件，并使用 gRPC 协议处理传入任务事件。
