# 更新日志

2026 年 1 月 15 日

## Sandboxes 的 OAuth 2.0 client credentials

Lattice 现在支持使用 OAuth 2.0 client credentials flow 进行机器到机器 (M2M) 认证。短期令牌让你可以更好地控制权限并提升安全性。

现有用户

在推出此新功能期间，我们会继续支持现有 Lattice 部署中的长期令牌。

如果你已有部署到生产 Lattice 环境的集成，建议与 Anduril 代表协作，确定迁移到 OAuth 2.0 client credentials flow 的时间表。

如果你正在 Lattice Sandboxes 中构建新集成，建议开始使用 OAuth 2.0 client credentials flow。

### 使用 OAuth 2.0 client credentials

你可以在 Sandboxes UI 的 Resource Credentials 区域找到 **Client ID** 和 **Client Secret**：

- Lattice Client ID：这是与你的集成关联的唯一公开标识符。
- Lattice Client Secret：这是你的集成用于向 Lattice 环境认证并证明自身身份的安全凭据。

在你的集成中，使用 **Lattice Client ID** 和 **Lattice Client Secret** 向 API 提交请求。

```
clientId := os.Getenv("LATTICE_CLIENT_ID")
clientSecret := os.Getenv("LATTICE_CLIENT_SECRET")

LatticeClient := client.NewClient(
    option.WithClientCredentials(clientID, clientSecret),
    option.WithBaseURL(fmt.Sprintf("https://%s", latticeEndpoint)),
    option.WithHTTPHeader(headers),
)
```

有关设置开发环境的更多信息，请参阅 *Lattice SDK 指南* 中的 [Set up](/guides/getting-started/set-up)。
