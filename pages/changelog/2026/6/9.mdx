# 更新日志

2026 年 6 月 9 日

## Lattice Developer Console

Lattice Developer Console 提供 Lattice 中数据的统一视图。可用它检查和调试实体、任务和对象。Developer Console 现在是 Lattice Sandboxes 在 `https://your_lattice_url.com/developer-console` 上的默认应用，但你仍可通过 `https://your_lattice_url.com/c2` 访问 operator 视图。

### 新增内容

- Entity Explorer：浏览、过滤和搜索 sandbox 中的每个实体。打开实体可检查其组件和任务，并使用提供的 schema 校验它是否格式正确。

![Shows the Entity Explorer in the Lattice Developer Console.](/img/anduril.docs.buildwithfern.com/72c242c7f0277f5a308bd2efb784cfcd9675f4dab9d1790bd9b195c6df74c7d0/assets/images/screenshots/developer-console-entity-explorer.png)

![Shows an entity's detail page in the Lattice Developer Console.](/img/anduril.docs.buildwithfern.com/e4304bc543cec0b7c859c63328414b293bdd7403ad7eb26f3d07066afaa15951/assets/images/screenshots/developer-console-entity-detail-page.png)

- Task Explorer：浏览每个任务，并检查其状态、生命周期和 payload。

![Shows the Task Explorer in the Lattice Developer Console.](/img/anduril.docs.buildwithfern.com/cf4ac4c786cb0ede10df0be80e3fd0dcb59f3479af80ae66a65cff589ab814d4/assets/images/screenshots/developer-console-task-detail-page.png)

- Object Explorer：浏览 sandbox 中存储的对象。

![Shows the Object Explorer in the Lattice Developer Console.](/img/anduril.docs.buildwithfern.com/76d4bcb7f3e0b163fc527c2d43a7643e9ab6607a0bbea6e8cdffc5ea465b081b/assets/images/screenshots/developer-console-object-explorer.png)

示例 C2 应用仍然可用，并在 Developer Console 中以 **Example C2 App** 链接提供。

要开始使用，请参阅 *Lattice SDK 指南* 中的 [Lattice Sandboxes](/guides/developer-tools/sandboxes)。
